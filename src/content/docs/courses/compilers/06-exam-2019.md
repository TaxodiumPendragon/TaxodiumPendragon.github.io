|------|------|------|

## 二、简答题（每小题 6 分，共 30 分）

### 1. 构造 DFA：识别能被 4 整除的正整数二进制表示（允许前导 0）

**思路：** 二进制数能被 4 整除，当且仅当**末两位为 `00`**。同时需排除数值为 0 的情况（正整数要求数值 > 0）。

**DFA 状态转移表：**

| 状态 | 含义 | 读 `0` | 读 `1` |
|------|------|--------|--------|
| A | 起始，尚未读入有效位 | B | D |
| B | 末位为 `0`，已读至少一位 | C（接受） | D |
| C | 末两位为 `00` | C（接受） | D |
| D | 末位为 `1`，非接受 | B | D |

- **接受状态：** C
- **附加约束：** 路径中至少出现过一次 `1`（排除仅由 `0` 组成的串，如 `"00"` 数值为 0，不是正整数）

> DFA 图示按上表画出即可；若需更严谨，可增加“是否出现过 1”的状态信息。

### 2. 表达式 `a*(b[i]+c/b[i-1])` 的翻译

#### 抽象语法树（AST）

```
        *
       / \
      a   +
         / \
      [ ]   /
     / \   / \
    b   i c  [ ]
            / \
           b   -
              / \
             i   1
```

（`[ ]` 表示数组下标运算。）

#### 四元式（三地址码）

```
(1) t1 = i - 1
(2) t2 = b[t1]
(3) t3 = c / t2
(4) t4 = b[i]
(5) t5 = t4 + t3
(6) t6 = a * t5
```

#### 间接三元式

将四元式操作数改为指向三元式表条目的指针或编号。本题中 `b[i]` 与 `b[i-1]` 下标不同，**无明显可共享子表达式**，间接三元式结构与四元式类似，仅操作数表示方式不同。

### 5. Python 到 C 的翻译 SDD

**核心数据结构：**

- **符号表栈（环境）：** 变量名 → 类型（`int` / `bool`）及版本号；
- **缩进计数栈：** 每个作用域对应一个 tab 计数；
- **错误标志：** 类型不匹配或 tab 不符时输出 `error`。

**SDD 框架（关键产生式及语义规则）：**

```
Code → Code Line     { Code.env = Line.env; 合并或传递 }
Code → ε             { /* 无操作 */ }

Line → Tabs Command  { 检查 Tabs.count == 当前缩进数；否则 error }
Tabs → Tabs tab      { Tabs.count = Tabs1.count + 1 }
Tabs → ε             { Tabs.count = 0 }

Command → if Bool :           { 进入新作用域，缩进 +1；Bool.type 必须为 bool }
Command → Variable = Rvalue   { 若 Rvalue.type ≠ Variable.type，则重新定义 Variable（版本 +1，更新类型）；否则普通赋值 }

Rvalue → Variable    { Rvalue.type = lookup(Variable.name).type }
Rvalue → Bool        { Rvalue.type = bool }
Rvalue → Int         { Rvalue.type = int }

Bool → Variable              { Bool.type = lookup(...).type；检查为 bool }
Bool → Bool1 and Bool2       { 两边均为 bool；Bool.type = bool }
Bool → Int1 > Int2           { 两边均为 int；Bool.type = bool }
Bool → true | false          { Bool.type = bool }

Int → Variable       { Int.type = lookup(...).type；检查为 int }
Int → Int1 + Int2    { 两边均为 int；Int.type = int }
Int → constant       { Int.type = int }

Variable → word      { Variable.name = word.val；环境中查找，不存在则报错 }
```

**翻译动作（`Variable = Rvalue`）：**

```
if (Rvalue.type != Variable.type) {
    生成新变量声明：类型 Rvalue.type，变量名 = ...;
    更新环境中的类型；
} else {
    生成普通赋值语句；
}
```

**额外处理：**

- 环境采用栈结构：`if` 进入时压入新作用域，离开时弹出；
- 缩进计数与 tab 数比较，错误时输出 `error` 并终止；
- 输出 C 代码直接拼接字符串，无需缩进。

## 三、LR 文法（10 分）

### 1. 补全 LR(1) 自动机

**增广文法：**

```
(0) S' → S
(1) S → B × S
(2) S → ε
(3) A → x B y
(4) A → x B
(5) B → x A x
(6) B → z
```

LR(1) 自动机缺失部分需根据**闭包**与**转移函数**补全。关键状态示例：

- **I0：** `S' → ·S, $`；`S → ·B×S, $`；`S → ·, $`（因 `S → ε`，在 I0 遇到 `$` 即可归约）

其余状态按 GOTO 函数逐步构造。

> 因原题图像缺失，无法在此精确补全全部状态。要点：若 `[A → α·Bβ, a]` 且 `B → γ` 是产生式，则加入 `[B → ·γ, FIRST(βa)]`。

---

### 2. 该文法是 SLR 还是 LR(0)？

| 类型 | 结论 | 理由 |
|------|------|------|
| LR(0) | **不是** | 含 `S → ε`，I0 中可能出现 `S → ·` 与 `S → ·B×S` 的移进-归约冲突 |
| SLR(1) | **是** | 用 Follow 集解决冲突；检查各冲突状态，归约项 Follow 集与移进终结符不相交 |

**答案：不是 LR(0)，是 SLR(1)。**

```

       / \
      B   C          (C.b = B.t,   C.w = B.width)

### 2. SDT 设计

```
B → B1 B2
{
    B1.x = B.x;  B1.y = B.y;
    B2.x = B.x + B1.width;  B2.y = B.y;

## 七、代码优化（10 分）

### 1. 数据流分析算法

| 项目 | 说明 |
|------|------|
| **方向** | 前向数据流：从循环入口观察表达式操作数是否在每次迭代中保持不变 |
| **状态** | 集合 `Invariant`，存储已判定为循环不变的表达式（或其编号），初始为空集 |
| **转移函数** | 对赋值 `x = y op z`：若 `y`、`z` 均为常量或在 `Invariant` 中且未被本语句修改，则将 `x = y op z` 加入 `Invariant`；否则若 `x` 被赋值，从 `Invariant` 中删除所有涉及 `x` 的表达式。条件跳转不改变集合 |
| **交汇操作** | 多前驱取**交集**（所有路径均不变的表达式才为循环不变） |
| **初始化** | 循环入口处，操作数应为常量或循环外定值 |

---

### 2. 代码中的循环不变表达式

**外循环（`i` 循环）：**

- `f / 2`：**不变**（`f` 为常量 6，在内层循环中不变）
- `b + 3`：**不是不变**（`b` 在内层循环中被修改：`b = j*2`）

**内层循环（`j` 循环）：**

- `i / 2`：**不变**（`i` 在外层循环定值，内层不变）
- `f / 2`：**不变**

**外移建议：**

- `i / 2` → 移到内层循环之前（仍在 `i` 循环内）；
- `f / 2` → 可移到所有循环之外（`f` 全程不变）。
