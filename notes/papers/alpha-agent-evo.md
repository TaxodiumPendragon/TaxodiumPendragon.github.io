> **一句话总结：** AlphaAgentEvo 用多轮工具交互式 GRPO 和五类分层奖励训练 1.7B/4B 模型，使模型不仅生成量化因子，还能围绕种子因子持续规划、反思和改进；论文报告其 4B 模型在 AlphaEvo500 与 Alpha158 上超过 GP、多智能体、ToolRL 和强闭源推理模型。

## 一、论文概览

### 1. 基本信息

- 论文已作为 ICLR 2026 conference paper 发表。
- 作者来自中山大学、南洋理工大学、Digital Trust Centre 和香港中文大学。
- 任务是公式化 Alpha 因子挖掘：给定历史市场特征和专家种子因子，通过多轮回测反馈生成更强、仍可解释的因子。
- 论文随补充材料提供训练、验证和测试划分、评估工具参数与训练配置；正文表示代码将在录用后公开。

### 2. 核心贡献

1. 将 Alpha mining 从彼此独立的“搜索-回测-重启”改写为围绕一个种子因子展开的连续演化轨迹。
2. 把 GRPO 扩展为多轮、工具在环的 Agentic RL：模型每轮读取完整历史，生成多个候选因子，由回测工具统一评价。
3. 设计包含工具调用、方向一致性、探索、性能和连续改进的分层奖励，引导模型从“会调用工具”逐步学到长程规划和反思。
4. 构建 AlphaEvo500，并在不同市场阶段和外部 Alpha158 因子库上检验有效率、演化成功率、多样性与样本外迁移。

### 3. 基本概念

- **Alpha factor**：根据历史市场特征预测未来收益的量化信号。
- **Alpha evolution**：优化对象不是单个因子，而是“如何从种子因子连续生成更优因子”的策略。
- **Agentic RL**：策略模型在 `think → propose/tool call → evaluate/tool response` 循环中接受强化学习更新。
- **Valid Ratio（VR）**：生成因子语法合法且能够执行回测的比例。
- **Pass@T**：前 `T` 轮生成结果中，是否存在 IR 非负且超过种子因子的候选，再对测试种子取平均。
- **AST similarity**：用抽象语法树节点重叠衡量两个公式结构的相似度，用于约束随机漂移和奖励多样化探索。

## 二、Motivation

### 1. 为什么不能把 Alpha mining 当普通搜索

Alpha 搜索空间极大，回测噪声和伪相关严重，每次评估还具有计算成本。如果每个候选都是一次孤立尝试，系统既不会利用失败反馈，也难以保留因子的语义逻辑。论文因此强调“evolution”：每轮修改都要建立在前几轮因子、回测结果和反思之上。

### 2. 现有方法的局限

- **Genetic Programming**：依赖随机变异和交叉，无法理解自然语言反馈，失败经验也很难转化为下一轮策略。
- **LLM/多智能体 Alpha 系统**：能表达语义，但常靠提示驱动；缺少训练出的长程规划和反思机制，容易在局部修改中重复打转。
- **普通工具 RL**：偏向单轮、单响应奖励，不能直接刻画跨轮演化质量，也未必约束因子仍围绕种子语义演化。
- **单一性能奖励**：金融数据高噪声，直接追逐回测得分容易暴力调用工具、过拟合局部市场或反复利用狭窄模式。

### 3. 核心观察

有效演化需要分阶段学习：先保证工具调用和表达式合法，再约束方向、鼓励新结构，最后优化性能和跨轮持续进步。奖励不能只是若干指标简单相加，还要体现“合法性是前提”“性能提升要与连续改进协同”等层级关系。

## 三、Method

### 1. 问题定义

给定种子因子分布 `D_seed`，策略 `π` 与回测工具交互 `T` 轮，得到演化集合 `F_π(f_seed)`。目标同时考虑演化期 `D_evo` 和样本外 `D_test` 的表现，并通过结构相似度约束把搜索限制在种子因子的可解释邻域内。

这里的关键变化是：训练目标从“输出一个高分公式”变成“学习一条能够反复改进公式的演化策略”。

### 2. 多轮 Agentic GRPO

每轮模型先分析既有轨迹，再并行提出 `k` 个因子工具调用。回测工具返回每个候选的执行状态和得分，结果被追加到下一轮上下文。训练时：

![AlphaAgentEvo 的多轮因子演化轨迹与 Agentic RL 训练过程](/assets/papers/agent-systems/alphaagentevo-fig02-training-overview.png)

*图 1：左侧展示单条 alpha-evolving trajectory 如何在每轮读取历史反馈、反思并并行提出新因子；右侧展示多条完整轨迹经过分层奖励、优势估计后用于 GRPO 更新。来源：论文 Figure 2。*

这张图强调了两个容易混淆的层级：一次“轨迹”本身包含多轮 Think/Tool Call/Tool Response，而一次策略更新又会同时比较同一种子产生的多条轨迹。奖励因此作用于长程演化行为，而不是把每个公式当作互不相关的单轮答案。

1. 对同一个种子采样一组完整演化轨迹。
2. 计算每条轨迹的总奖励，并在组内标准化得到相对优势。
3. 只对模型生成的 reasoning/tool-call token 反向传播；工具返回内容参与上下文但不产生梯度。
4. 使用 clipped policy ratio 和相对参考策略的 KL 惩罚更新模型。

这使优化单位成为整条多轮轨迹，模型能学习“上一轮为什么失败、下一轮改变什么”，而不是对每次工具调用独立打分。

### 3. 分层奖励函数

奖励由五个部分组成：

| 奖励 | 作用 | 设计要点 |
| --- | --- | --- |
| Tool Call Reward | 学会正确、节制地使用回测工具 | 成功调用加分、失败调用扣分，并按调用成本归一化 |
| Consistency Reward | 避免完全偏离种子语义 | 当候选与种子的 AST 相似度高于下界 `0.1` 时奖励 |
| Exploration Reward | 避免反复生成相似公式 | 根据候选与此前所有公式的最大相似度给予反向奖励 |
| Performance Reward | 奖励优于种子的因子 | 对性能差值做平滑的对数缩放，降低高噪声极值影响 |
| Streak Reward | 奖励连续多轮进步 | 取轨迹中连续改进序列的最长长度 |

总奖励不是简单相加：一致性和探索收益受工具调用项约束；性能奖励与 streak 奖励相乘，要求“高分”与“持续进步”同时出现；每项还有上限，避免某一信号压倒其他目标。

### 4. 训练配置

- 基座：Qwen3 1.7B 与 4B。
- 训练：10 张 RTX 4090，Verl 框架，150 steps；测试使用 step 80 checkpoint。
- 每批 20 个种子，每个种子 3 条 rollout；每条轨迹最多 3 轮，每轮最多 4 次工具调用。
- 学习率 `1e-6`，KL 系数 `0.001`，Adam，policy mini-batch 20。
- 训练只使用 2023-01-01 至 2024-01-01 的一年市场数据，以降低迭代成本。

## 四、Evaluation

### 1. 数据和协议

- **AlphaEvo500**：350 个训练种子、50 个验证种子、100 个测试种子。
- **Alpha158**：作为额外的外部测试因子库。
- **市场**：HS300 和 CSI500；覆盖 2023-2024 熊市阶段与 2024-2025 牛市阶段。
- **交易协议**：单因子信号，每 5 个交易日调仓，做多截面排名前 10% 的股票。
- **指标**：VR、Pass@3、Pass@5、Annualized Excess Return（AER）和 Information Ratio（IR）。
- **公平性**：主要方法共享同一回测工具和工具调用预算，默认每轮 4 个 offspring。

### 2. AlphaEvo500 结果

在 2024-2025 市场阶段：

| 方法 | HS300 VR / Pass@3 / Pass@5 | CSI500 VR / Pass@3 / Pass@5 |
| --- | --- | --- |
| GPT-5-mini | 0.970 / 0.75 / 0.88 | 0.972 / 0.73 / 0.82 |
| GEPA + GPT-5-mini | 0.992 / 0.87 / 0.90 | 0.971 / 0.86 / 0.91 |
| AlphaAgentEvo-1.7B | 0.940 / 0.77 / 0.90 | 0.923 / 0.76 / 0.78 |
| **AlphaAgentEvo-4B** | **0.979 / 0.97 / 0.97** | **0.977 / 0.93 / 0.95** |

![AlphaAgentEvo 在 AlphaEvo500 的 HS300 与 CSI500 结果](/assets/papers/agent-systems/alphaagentevo-table01-alphaevo500.png)

*图 2：AlphaEvo500 主结果。4B 模型在两个市场的 Pass@3/Pass@5 上均为表中最佳；VR 最优则由不同 GEPA 配置取得，因此不能把“通过率最佳”表述为所有指标全面最佳。来源：论文 Table 1。*

4B 模型在两类市场上都取得最高 Pass rate；它最多只训练 3 轮，却在 Pass@5 上仍保持优势，说明策略能延伸到更长轨迹。

### 3. Alpha158 外部测试

AlphaAgentEvo-4B 在 2023-2024 阶段达到 `VR=0.982, Pass@3=0.581, Pass@5=0.725`；在 2024-2025 阶段达到 `0.982 / 0.963 / 0.994`。传统 GP 在相同预算下明显较弱，强推理模型在不同市场阶段也不够稳定。

### 4. 多样性和样本外迁移

- 4B 模型生成的 Top-20 因子平均两两 AST 相似度为 `0.039`，最大值为 `0.263`；DeepSeek-R1 和 Qwen3-4B 的最大相似度分别达到 `0.583` 和 `0.600`。
- 在两个样本外测试阶段，论文控制各模型候选在演化期拥有相同平均 IR，再比较后续 AER/IR；AlphaAgentEvo-4B 的平均值均高于 GPT-5-mini 和 DeepSeek-R1。
- 多因子组合实验中，AlphaAgentEvo-4B 报告 `AER=0.129, IR=2.442, MDD=-0.176`，优于表中其他方法。

### 5. 消融与案例

- 移除 exploration 或 consistency reward 都会降低 Pass rate；AlphaEvo500 的 Pass@3 从 `0.65` 降至 `0.54/0.51`，Alpha158 从 `0.581` 降至 `0.513/0.510`。
- 案例中，普通 Qwen3-4B 主要调整窗口和 Z-score；AlphaAgentEvo 会先检查因子方向是否符合交易语义，再从成功候选总结 RSI、波动率和摆动点等结构模式。第二轮进一步提出行业中性化和 ATR 调整，最佳示例 IR 达 `1.1863`。

## 五、局限与开放问题

1. 论文实验集中于公式化量化因子；“分层奖励能训练出通用自演化能力”还需要在其他工具任务上验证。
2. Pass 与回测 IR 仍受市场噪声、数据挖掘偏差和交易协议影响；论文结果不是可直接部署的投资收益承诺。
3. 奖励包含多个手工权重、阈值和 cap，尚不清楚对不同任务和市场的敏感性。
4. 结构相似度基于 AST overlap，能约束语法结构，却不等价于经济含义或行为相似度。
5. 样本外区间仍与系统开发时间相近，长期跨市场、跨资产和交易成本鲁棒性需要更强检验。

## 六、个人思考与 AProf 关联

### 1. 可借鉴点

- **奖励分层而非平铺**：AProf 可按“工具调用合法 → 编译成功 → 正确性通过 → 性能改善 → 连续多轮改善”组织奖励。正确性必须是硬门控，而不是与速度加权抵消。
- **Streak reward 的迁移**：连续几轮稳定改进可以奖励策略质量，但必须防止模型把一个完整优化拆成许多微小改动刷 streak。
- **探索与一致性并存**：算子优化中可用 patch/机制相似度抑制重复尝试，同时用语义与适用范围约束避免完全漂移。
- **轨迹级学习**：一次优化失败、修复、重新 profiling 和下一次选择应作为连续轨迹，而不是互不相关的候选样本。
- **行为证据**：论文通过随轮次增长的 IR、探索方差和稳定一致性解释 agent-level evolution。AProf 也应区分“候选代码变了”和“策略真的学会了利用历史”。

### 2. 迁移时必须修改的部分

- 金融回测能廉价并行评估公式；算子优化需要编译、正确性和真实设备计时，奖励成本高得多。
- AProf 的一致性约束不应只看 AST，而要包含算子语义、dtype、shape、动态边界和硬件适用范围。
- 性能奖励应基于稳定的配对测量与置信界；profiling 指标只用于解释和路由，不应直接替代端到端时延。
- 工具调用成本可扩展为编译次数、NPU 时间、full profiling 次数和 token 成本。

### 3. 阅读中的问题

- 分层奖励的乘法与截断是否会造成大量轨迹梯度为零？各项权重的敏感性如何？
- 训练仅 3 轮而报告 Pass@5 泛化很有价值，但更长轨迹是否会出现策略漂移或 reward hacking？
- 如果回测工具返回不同市场阶段的证据，模型是否真正识别 regime shift，还是只学到了通用公式重写模式？
- 与 SAGE/SkillOpt 结合时，能否把成功演化轨迹蒸馏为可验证技能，而不仅保留在模型权重中？

## 七、结论

AlphaAgentEvo 最值得借鉴的不是“用 RL 找因子”，而是把多轮工具反馈、连续改进和方向约束编码为轨迹级分层奖励。它展示了小模型通过任务特定 ARL 超过强闭源模型的可能性；同时也提醒我们，自演化主张必须由长期行为、外部分布和奖励消融共同支撑。
