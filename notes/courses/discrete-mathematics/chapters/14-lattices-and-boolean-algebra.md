# 14格与布尔代数

## 格的定义与性质

格有两种等价的定义方式，一种从偏序关系出发，另一种从代数运算出发。

### 格的偏序集定义

一个**格**首先是一个**偏序集** $\langle S, \le \rangle$，它额外满足一个关键条件：对于集合 $S$ 中的**任何**两个元素组成的子集（即任意一对元素 $\{a, b\}$），都存在唯一的**最大下界**和唯一的**最小上界**。

最大下界和最小上界的概念，催生了格中的两种基本运算：
- **交运算**，记作 $\land$：$a \land b$ 定义为 $\{a, b\}$ 的最大下界。
- **并运算**，记作 $\lor$：$a \lor b$ 定义为 $\{a, b\}$ 的最小上界。

因此，一个偏序集 $\langle L, \le \rangle$ 是一个格，就等价于说它能够导出一个具有两种二元运算的代数系统 $\langle L, \land, \lor \rangle$。

一些经典的格的实例包括：
- **正因子格**：集合为正整数 $n$ 的所有正因子，偏序关系为“整除”。此时，交运算 $\land$ 对应于求**最大公约数** $\gcd$，并运算 $\lor$ 对应于求**最小公倍数** $\operatorname{lcm}$。
- **幂集格**：集合为某个集合 $B$ 的幂集 $P(B)$，偏序关系为“集合包含” $\subseteq$。此时，交运算 $\land$ 对应于**集合交集** $\cap$，并運算 $\lor$ 对应于**集合并集** $\cup$。

### 格的代数定义

一个代数系统 $\langle L, \land, \lor \rangle$ 如果带有两个二元運算，并且这两个運算都满足**交換律**、**結合律**以及相互之間的**吸收律**，那么這個系統就是一個格。吸收律指的是 $a \land (a \lor b) = a$ 和 $a \lor (a \land b) = a$。

这个代数定义与偏序集定义是等价的。我们可以通过代数运算来定义偏序关系，例如，定义 $a \le b$ 当且仅当 $a \land b = a$（或者等价地，$a \lor b = b$）。可以证明，这样定义出的关系 $\le$ 满足自反、反对称和传递性，从而构成一个偏序关系，并且在该偏序关系下任意两个元素都有最大下界和最小上界。

### 格的性质

- **对偶原理**：这是一个关于格的元定理，它指出，任何一个对于所有格都成立的命题，如果我们将其中所有的 $\le$ 换成 $\ge$，$\ge$ 换成 $\le$，$\land$ 换成 $\lor$，$\lor$ 换成 $\land$，得到的新命题（称为原命题的对偶命题）也必然对所有格成立。这个原理极大地简化了格理论的证明，因为证明了一个命题，其对偶命题就自动成立。
- **基本性质**：由定义可以直接推导出交换律、结合律、幂等律和吸收律。
- **保序不等式**：如果 $a \le b$ 且 $c \le d$，那么 $a \land c \le b \land d$ 且 $a \lor c \le b \lor d$。
- **分配不等式**：在任何格中，都满足 $a \lor (b \land c) \le (a \lor b) \land (a \lor c)$ 以及其对偶形式 $a \land (b \lor c) \ge (a \land b) \lor (a \land c)$。

## 分配格、有补格与布尔代数

通过在格的结构上增加更多的约束条件，我们可以得到更特殊的、性质更丰富的代数结构。

### 分配格

如果一个格中的分配不等式可以取等号，即交运算和并運算相互之间满足**分配律**，那么这个格就被称为**分配格**。
并非所有的格都是分配格。两个经典的非分配格是**钻石格**（$M_3$）和**五角格**（$N_5$）。一个重要的定理指出，一个格是分配格，当且仅当它不包含任何与钻石格或五角格同构的子格。

### 有界格与有补格

- **有界格**：如果一个格中存在一个**全下界**（通常记作 **0**），它小于等于格中所有元素；并且存在一个**全上界**（通常记作 **1**），它大于等于格中所有元素，那么这个格就是有界的。
- **有补格**：在一个有界格中，对于一个元素 $a$，如果存在一个元素 $b$ 使得 $a \land b = 0$ 且 $a \lor b = 1$，那么称 $b$ 是 $a$ 的**补元**。如果格中的**每个**元素都存在补元，则称该格为有补格。
在一般的格中，一个元素的补元可能不唯一。但是，在一个**有界分配格**中，如果一个元素存在补元，那么这个补元是**唯一**的。

### 3布尔代数

**布尔代数**是格理论的顶峰，它是一种性质非常完善的代数结构。一个格如果既是**分配格**，又是**有补格**，那么它就是一个布尔格，或称为布尔代数。

布尔代数可以被看作是一个代数系统 $\langle B, \land, \lor, ', 0, 1 \rangle$，其中 $\land$ 和 $\lor$ 满足交换、结合、吸收、分配律，$0$ 和 $1$ 是单位元，而 $'$ 是一元运算（求补元），满足 $a \land a' = 0$ 和 $a \lor a' = 1$。

布尔代数具有许多优美的性质，例如双重否定律 $(a')' = a$ 和德摩根律 $(a \land b)' = a' \lor b'$。

### 有限布尔代数的结构

- **原子**：在有界格中，一个直接“覆盖”全下界0的非零元素被称为原子。
- **定理**: 任何一个有限布尔代数，都必然**同构**于它的全体原子构成的集合的**幂集代数**。

这个定理揭示了所有有限布尔代数的本质。它告诉我们，任何有限布尔代数在结构上都和一个幂集格 $\langle P(A), \cap, \cup \rangle$ 是完全一样的。这也直接导出了一个重要推论：任何有限布尔代数的元素个数必然是 $2^n$（其中 $n$ 是原子的个数）。并且，任何两个具有相同元素个数的有限布尔代数一定是同构的。
