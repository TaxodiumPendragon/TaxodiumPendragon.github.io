- **图的定义及运算**
    - **基本定义**
        - **无向图 (Undirected Graph)**: 顶点集 $V$ 与边集 $E$ 构成的二元组 $\langle V, E \rangle$，边是顶点的**无序对**。
        - **有向图 (Directed Graph)**: 边是顶点的**有序对**（弧）。
    - **核心概念**
        - **阶**: 顶点数 $|V|$。
        - **相邻**: 两个顶点被同一条边连接。
        - **关联**: 边与它的端点。
        - **环 (Loop)**: 边的两个端点是同一个顶点。
        - **孤立点**: 不与任何边关联的顶点。
        - **基图**: 有向图忽略方向后得到的无向图。
        - **邻域**：N(v),相邻点，闭邻域就是包含自己。I(v)就是关联集；后继元集是有向图里找后继，符号是+
        
    - **特殊图**
        - **简单图**: 无环且无平行边。
        - **多重图**: 含有平行边。
        - **零图**: 边集为空。
        - **空图**: 顶点集为空。
        - **n阶完全图$K_n$**:每个顶点都和其余n-1个顶点香菱
        - **n阶竞赛图**：如果有向简单图的基图是n阶无向完全图
    - **子图**
        - **子图 (Subgraph)**: 顶点集和边集都是原图的子集。
        - **生成子图 (Spanning Subgraph)**: 包含原图的所有顶点。
    - **图运算**
        - 并、交、差、环和。

- **度数、通路与回路**
    - **度数 (Degree)**
        - **无向图**: $d(v)$，与顶点关联的边数（环计2次）。
        - **有向图**:
            - **出度 $d^+(v)$**: 以顶点为始点的边数。
            - **入度 $d^-(v)$**: 以顶点为终点的边数。
        - **握手定理**:
            - **无向图**: $\sum d(v) = 2|E|$ (度数和是边数的2倍)。
            - **有向图**: $\sum d^+(v) = \sum d^-(v) = |E|$ (总出度=总入度=边数)。
            - **推论**: 任何图中，奇度顶点的个数为偶数。
        - **可图化**: 一个非负整数序列能成为某图的度数列（充要条件：序列和为偶数）。
        - **k-正则图**：每个点的度数都为k
    - **通路与回路**
        - **通路 (Walk)**: 顶点和边的交替序列。
        - **回路 (Circuit)**: 起点和终点相同的通路。
        - **简单通路/回路 (Trail/Tour)**: **边**不重复。
        - **初级通路/路径 (Path)**: **顶点**不重复。
        - **初级回路/圈 (Cycle)**: **顶点**不重复（除首尾外）。*长度相等的圈都是同构的*

- **图的连通性**
    - **无向图连通性**
        - **连通图**: 任意两顶点间都存在通路。
        - **连通分支**: 非连通图中的极大连通子图。
        - **点割集/割点**: 移除后使连通分支数增加的顶点（集）。
        - **边割集/桥**: 移除后使连通分支数增加的边（集）。
        - **连通度**:
            - **点连通度 $\kappa(G)$**: 最少需要移除的顶点数。
            - **边连通度 $\lambda(G)$**: 最少需要移除的边数。
            - **关系**: $\kappa(G) \le \lambda(G) \le \delta(G)$ (最小度)。
    - **有向图连通性**
        - **可达**: 两顶点间存在有向通路。
        - **弱连通**: 基图是连通的。
        - **单向连通**: 任意两顶点 $u, v$，$u$ 可达 $v$ 或 $v$ 可达 $u$ 至少成立一个。
        - **强连通**: 任意两顶点相互可达。
    - **二部图**
        - **定义**: 顶点集可划分为两个独立集 $V_1, V_2$，所有边都跨越这两个集合。
        - **判定定理**: 一个图是二部图**当且仅当**它不含任何奇数长度的圈。
        - **完全二部图**：$K_{m,n}$，其中m，n分别是二部图两个顶点集的顶点个数。$K_{3,3}$是重要的平面图工具，$K_{1,4}$是简单的星形图。(V1中每个端点都跟V2的点相邻)

- **图的矩阵表示**
    - **关联矩阵 $M(G)$**
        - 描述**顶点与边**的关系。
        - **无向图**: 元素 $m_{ij}$ 表示顶点 $v_i$ 与边 $e_j$ 的关联次数。
        - **有向图**: 元素为 +1 (始点), -1 (终点), 0 (不关联)。
    - **邻接矩阵 $A(G)$**
        - 描述**顶点与顶点**的关系。
        - 元素 $a_{ij}$ 表示从 $v_i$ 到 $v_j$ 的边数。
        - **重要性质**: $A^l$ 的 $(i,j)$ 元素值等于从 $v_i$到 $v_j$ 长度为 $l$ 的通路数。
    - **可达矩阵 $P(D)$**
        - 描述顶点间的可达性。
        - 元素 $p_{ij}$ 为 1 (可达) 或 0 (不可达)。

### 最小度δ(G)
- **定义**: 图中所有顶点的度中的**最小值**。
- **含义**: 反映了图中“联系最弱”的顶点的连接情况。

### 最大度Δ(G)
- **定义**: 图中所有顶点的度中的**最大值**。
- **含义**: 反映了图中“联系最紧密”的顶点的连接情况。
