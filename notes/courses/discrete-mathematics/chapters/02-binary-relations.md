- **1. 基础概念：有序对与笛卡儿积**
    - **有序对 (Ordered Pair)**: `⟨x, y⟩`
        - **核心**: 顺序至关重要, `⟨x, y⟩ ≠ ⟨y, x⟩` (除非 x=y)。
        - **相等条件**: `⟨x, y⟩ = ⟨u, v⟩` 当且仅当 `x = u` 且 `y = v`。
    - **笛卡儿积 (Cartesian Product)**: `A × B`
        - **定义**: ` { ⟨x, y⟩ | x ∈ A ∧ y ∈ B } ` (所有可能的有序对的集合)。
        - **性质**:
            - 不满足交换律和结合律。
            - 对并集 (∪) 和交集 (∩) 满足分配律。
            - `A × ∅ = ∅`。

- **2. 二元关系 (Binary Relation)**
    - **核心定义**: 笛卡儿积 `A × B` 的一个**子集**。
        - **从 A 到 B 的关系**: `R ⊆ A × B`。
        - **A 上的关系**: `R ⊆ A × A`。
    - **特殊关系 (在集合 A 上)**
        - **空关系 (Empty Relation)**: `∅`。
        - **全域关系 (Universal Relation)**: `E_A = A × A`。
        - **恒等关系 (Identity Relation)**: `I_A = {⟨x, x⟩ | x ∈ A}`。
    - **表示方法**
        - **集合表达式**: 直接列出所有有序对。
        - **关系矩阵 (Matrix)**: `M_R`，一个 0/1 矩阵，`m_ij = 1` 表示 `⟨i, j⟩ ∈ R`。
        - **关系图 (Graph)**: 一个有向图，顶点是集合元素，边是关系中的有序对。

- **3. 关系的运算**
    - **基本运算**: `定义域 (dom R)`, `值域 (ran R)`, `域 (fld R)`。
    - **逆关系 (Inverse)**: `R⁻¹ = {⟨y, x⟩ | ⟨x, y⟩ ∈ R}` (交换元素位置)。
    - **复合 (Composition)**: `F ◦ G = {⟨x, z⟩ | ∃y, ⟨x, y⟩ ∈ F ∧ ⟨y, z⟩ ∈ G}` (通过中间元素`y`连接)。
    - **幂运算 (Power)**: `Rⁿ` (关系与自身的n-1次复合)。
        - `R⁰ = I_A` (恒等关系)。
        - `R¹ = R`。
        - `Rⁿ` 对应关系图中长度为 `n` 的路径。

- **4. 关系的性质 (核心)**
    - **自反性 (Reflexive)**: `∀x ∈ A, ⟨x, x⟩ ∈ R` (每个元素都与自身相关)。
        - **矩阵**: 主对角线元素全为 1。
        - **图**: 每个顶点都有一个自环。
    - **反自反性 (Irreflexive)**: `∀x ∈ A, ⟨x, x⟩ ∉ R` (没有元素与自身相关)。
        - **矩阵**: 主对角线元素全为 0。
        - **图**: 没有任何顶点有自环。
    - **对称性 (Symmetric)**: `若 ⟨x, y⟩ ∈ R, 则 ⟨y, x⟩ ∈ R` (关系是双向的)。
        - **代数**: `R = R⁻¹`。
        - **矩阵**: 矩阵是还给的对称矩阵。
        - **图**: 顶点间的边都是双向边。
    - **反对称性 (Antisymmetric)**: `若 ⟨x, y⟩ ∈ R 且 ⟨y, x⟩ ∈ R, 则 x = y` (不同元素间关系是单向的)。
        - **矩阵**: `若 i ≠ j`, 则 `m_ij` 和 `m_ji` 中最多有一个为 1。
        - **图**: 任意两个不同顶点之间没有双向边。
    - **传递性 (Transitive)**: `若 ⟨x, y⟩ ∈ R 且 ⟨y, z⟩ ∈ R, 则 ⟨x, z⟩ ∈ R` (关系链可以“抄近路”)。
        - **代数**: `R ◦ R ⊆ R`。
        - **图**: 如果存在 `x → y` 和 `y → z` 的路径，则一定存在 `x → z` 的直接边。

- **5. 关系的闭包 (Closure)**
    - **目标**: 添加最少的有序对使关系满足特定性质。
    - **自反闭包 `r(R)`**: `R ∪ I_A` (加上所有自环)。
    - **对称闭包 `s(R)`**: `R ∪ R⁻¹` (加上所有反向边)。
    - **传递闭包 `t(R)`**: `R ∪ R² ∪ R³ ∪ ...` (加上所有“快捷方式”边)。
        - **算法**: Warshall 算法。

- **6. 两种重要的关系类型**
    - **等价关系 (Equivalence Relation)**
        - **定义**: **自反、对称、传递**。
        - **作用**: 对集合进行**分类**。
        - **等价类 `[x]`**: 与 `x` 等价的所有元素的集合。
        - **划分 (Partition)**:
            - **定义**: 将集合分割成若干非空、不交的子集，其并集为原集合。
            - **核心洞察**: 集合上的**等价关系**与该集合的**划分**是**一一对应**的。
        - **商集 `A/R`**: 所有等价类构成的集合。
    - **偏序关系 (Partial Order Relation)**
        - **定义**: **自反、反对称、传递**。
        - **作用**: 定义集合中元素的**顺序**。
        - **核心特点**: 不要求任意两个元素都**可比**。
            - **全序关系 (Total Order)**: 任意两个元素都可比的偏序。
        - **哈斯图 (Hasse Diagram)**: 偏序关系的一种简化、直观的图形表示。
        - 覆盖的概念本质就是哈斯图里的相邻，标准定义就是中间没有x < z < y，以此来形成哈斯图
            - **规则**: 移除自环、传递边，用上下位置表示方向。
        - **特殊元素**: 极大/极小元, 最大/最小元, 上/下界，上下确界/最小上届/最大下界。（极与最的区别是极可以不可比）
