- **1. 函数的定义与性质**
    - **核心定义 (作为特殊的二元关系)**
        - **函数/映射**: 一个二元关系，其中每个定义域元素 `x` 对应**唯一**的 `y`。
        - B上A，$B^A$是指所有从A到B的函数集合
        - **表示法**: `f: A → B`
            - `A`: **定义域 (Domain)** - 输入的集合。
            - `B`: **陪域 (Codomain)** - 可能输出值所在的集合。
            - `ran f` (值域/Range): 实际输出值的集合，`ran f ⊆ B`。
    - **像与原像**
        - **像 (Image)** `f(A₁)`: 定义域子集 `A₁` 的输出集合。
        - **原像 (Preimage)** `f⁻¹(B₁)`: 映射到陪域子集 `B₁` 的输入集合。
    - **函数类型 (关键分类)**
        - **单射**: 不同的输入得到不同的输出。
            - `f(x₁) = f(x₂) ⇒ x₁ = x₂`
        - **满射**: 陪域中的每个元素都被映射到。
            - `ran f = B`
        - **双射**: 既是单射又是满射。
            - 在集合间建立**一一对应**关系，是定义“等势”的基础。
    - **特殊的函数**
        - **常函数**: `f(x) = c`，所有输入映射到同一个输出。
        - **恒等函数**: $I_A(x) = x$，输入等于输出。
        - **特征函数**: $\chi_A$，用于判断元素是否属于某个子集。
        - 
        - **自然映射**: `g(a) = [a]`，将元素映射到其所在的等价类，即对象是A/R商集。仅有恒等关系确定的自然映射是双射，其他一般是满射

- **2. 函数的复合与反函数**
    - **函数复合**
        - **表示法**: `g ∘ f`
        - **定义**: `(g ∘ f)(x) = g(f(x))` (**先用**`f`，再用`g`)。
        - **性质**:
            - 满足**结合律**: `(h ∘ g) ∘ f = h ∘ (g ∘ f)`。
            - **性质保持**: 单射的复合是单射，满射的复合是满射，双射的复合是双射。
    - **反函数 (Inverse Function)**
        - **存在条件**: 原函数 `f` **必须是双射**。
        - **表示法**: `f⁻¹: B → A`。
        - **性质**:
            - `f⁻¹` 也必然是双射。
            - `f⁻¹ ∘ f = I_A` (定义域上的恒等函数)。
            - `f ∘ f⁻¹ = I_B` (陪域上的恒等函数)。

- **3. 双射函数与集合的基数**
    - **核心思想**: 使用**双射**来比较集合的大小，特别是无穷集合。
    - **集合等势 (Equipotence)**
        - **定义**: 若集合 `A` 和 `B` 之间存在双射，则称它们等势，记作 `A ≈ B`。
        - **重要结论**:
            - $ℕ ≈ ℤ ≈ ℚ≈ ℕ \times ℕ$ (自然数、整数、有理数集等势)。
            - $ℕ \times ℕ$使用的双射函数是$f(<m,n>)=\frac{(m+n+1)(m+n)}{2}+m$,另外的Q借助可数，Z错位双射即可
            - $ℝ ≈ (0, 1) ≈ [0, 1]$ (实数集与任何区间等势)。分别利用tan函数$tan\frac{2x-1}{2}\pi$和错位双射
    - **基数 (Cardinality)**
        - **概念**: 集合“大小”的度量，记作 `card(A)` 或 `|A|`。
        - **有穷基数**: 0, 1, 2, ...
        - **无穷基数**:
            - `ℵ₀` (阿列夫零): **可数集** (与 `ℕ` 等势) 的基数，是最小的无穷基数。
            - `ℵ` (或 `c`): **实数集**的基数。
    - **康托定理 (Cantor's Theorem)**
        - **核心结论**: 揭示了无穷是有层次的。
            1.  `ℕ ≉ ℝ` (自然数集和实数集不等势，`ℵ₀ < ℵ`)。
                - **证明方法**: **对角线法**。
            2.  $A ≉ P(A)$ (任何集合都与其幂集不等势)。
                - **推论**: 不存在“最大的集合”或最大的基数。
    - **可数集 (Countable Set)**
        - **定义**: 与自然数集 `ℕ` 等势或有穷的集合 (`card(A) ≤ ℵ₀`)。
        - **性质**: 元素可以被一一列出。
        - 无穷集的幂集不是可数集
        - 可数集的任何子集都是可数集
        - 可数个可数集的并是可数的
        - 两个可数集的笛卡尔积是可数集
