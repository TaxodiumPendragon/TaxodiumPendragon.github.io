### **试题逐题解析**

#### **一、不定项选择题**

**1. 下面哪些是集合{a, {0}, {a,b}, c, d}的子集?**
*   **答案**: A, B, D
*   **考察知识点**: 集合论基础、元素与子集的概念。
*   **解析**:
    *   集合的**元素**是直接隶属于该集合的成员。该集合的元素是：`a`, `{0}`, `{a,b}`, `c`, `d`。
    *   集合的**子集**是由该集合中零个或多个元素组成的集合。
    *   A. `{a}`: 元素 `a` 在原集合中，所以由它组成的集合 `{a}` 是原集合的子集。正确。
    *   B. `Ø`: 空集是任何集合的子集。正确。
    *   C. `{a,b}`: `{a,b}` 本身是原集合的一个**元素**，而不是一个子集。要成为子集，它的成员 `a` 和 `b` 都必须是原集合的元素，但 `b` 不是。错误。
    *   D. `{a,c}`: 元素 `a` 和 `c` 都在原集合中，所以由它们组成的集合 `{a,c}` 是原集合的子集。正确。

**2. 下面哪些关系是等价关系?**
*   **答案**: B, C
*   **考察知识点**: 关系的性质、等价关系的定义。
*   **解析**: 等价关系必须同时满足**自反性**、**对称性**和**传递性**。
    *   A. 整数的整除关系：满足自反性(a|a)和传递性(若a|b且b|c, 则a|c)，但不满足对称性(例如2|4，但4不整除2)。因此不是等价关系。
    *   B. 无向图中顶点可达关系：两顶点间存在路径。满足自反性(任一顶点到自身可达)、对称性(无向图中u到v可达，则v到u也可达)和传递性(若u到v可达，v到w可达，则u到w可达)。因此是等价关系，其等价类是图的连通分量。
    *   C. 整数的模55同余关系：满足自反性(a≡a mod 55)、对称性(若a≡b, 则b≡a)和传递性(若a≡b, b≡c, 则a≡c)。因此是等价关系。
    *   D. 偏序关系：定义为满足自反性、反对称性和传递性。因其不一定满足对称性，所以不是等价关系。

**3. 以下哪些集合与自然数集N等势?**
*   **答案**: A, B, C
*   **考察知识点**: 集合的势、可数集（可数无穷集）。
*   **解析**: 与自然数集N等势的集合是**可数无穷集**。
    *   A. N×N：自然数对的集合。可以通过对角线法（康托尔配对函数）证明其与N一一对应，是可数无穷集。
    *   B. 全体素数集合：素数集合是自然数集的无限子集，因此是可数无穷集。
    *   C. 所有有理数集合 (Q)：有理数可以表示为p/q的整数对，可以证明有理数集与N×N等势，因此是可数无穷集。
    *   D. P(N) (N的幂集)：根据康托尔定理，任何集合的幂集的势都严格大于该集合的势。P(N)的势是连续统的势，是不可数集。

**4. 关于正整数2023和119的正确说法有( )。**
*   **答案**: C, D
*   **考察知识点**: 数论、整除、互素、同余。
*   **解析**: 首先对2023和119进行质因数分解。
    *   119 = 7 × 17
    *   2023 = 7 × 289 = 7 × 17²
    *   A. 2023是素数：错误，它可以被7和17整除。
    *   B. 2023与119互素：错误，它们有公因子7和17，最大公约数是119。
    *   C. 119整除2023：正确，2023 / 119 = (7 × 17²) / (7 × 17) = 17。
    *   D. 2023和119是模16同余的：
        *   2023 = 16 × 126 + 7，所以 2023 ≡ 7 (mod 16)。
        *   119 = 16 × 7 + 7，所以 119 ≡ 7 (mod 16)。
        *   两者模16的余数相同，因此是同余的。正确。

**5. 若简单图G有度数列(1,1,2,2,3,3),则下列说法一定正确的是( )。**
*   **答案**: B
*   **考察知识点**: 图论基本概念、握手定理、树与环。
*   **解析**:
    *   图有 n=6 个顶点。
    *   根据握手定理，边的数量 m = (1+1+2+2+3+3) / 2 = 6。
    *   A. 图G是树：树的条件是 m = n-1。这里 m=6, n-1=5，m > n-1，所以G一定不是树，必定含有回路。错误。
    *   B. 图G有初级回路：因为 m=n，任何一个含有n个顶点n条边的图至少有一个回路（初级回路）。正确。
    *   C. 图G是连通图：不一定。例如，该图可以由一个 K₂(两个顶点一条边，度为1,1)和一个 K₄-e (四阶完全图去掉一条边，度为2,2,3,3)两个不连通的组件构成。所以不一定是连通图。错误。
    *   D. 图G恰有4种互不同构的：图的同构计数通常很复杂，无法轻易断定。且B选项是基于图的基本性质得出的必然结论。

**6. 5阶竞赛图可能同时是( )。**
*   **答案**: A, C, D
*   **考察知识点**: 图论、竞赛图、欧拉图、哈密顿图。
*   **解析**: 5阶竞赛图是5个顶点的有向完全图。
    *   **欧拉图**：一个有向图是欧拉图，当且仅当它强连通且每个顶点的入度等于出度。对于5阶竞赛图，要成为欧拉图，每个顶点的出度（和入度）都必须是 (5-1)/2 = 2。这样的图称为正则竞赛图，是存在的。
    *   **哈密顿图**：一个竞赛图有哈密顿回路，当且仅当它是强连通的。
    *   A. 有向欧拉图和有向哈密顿图：一个5阶正则竞赛图，每个点出度为2，它是强连通的，所以既是欧拉图也是哈密顿图。这种情况可能。
    *   B. 有向欧拉图但不是有向哈密顿图：不可能。因为有向欧拉图必须强连通，而强连通的竞赛图必有哈密顿回路。
    *   C. 有向哈密顿图但不是有向欧拉图：可能。只要竞赛图是强连通但不是正则的（即存在顶点入度不等于出度），它就是哈密顿图但不是欧拉图。这是可能的。
    *   D. 不是有向欧拉图也不是有向哈密顿图：可能。一个非强连通的竞赛图（例如传递竞赛图）就没有哈密顿回路，也肯定不是欧拉图。

**7. 下面4个图中,仅有( )是平面图。**
*   **答案**: D
*   **考察知识点**: 图论、平面图的判别、库拉托夫斯基定理。
*   **解析**:
    *   A: K₅ (5阶完全图)，根据库拉托夫斯基定理，K₅不是平面图。
    *   B: K₃,₃ (完全二分图)，根据库拉托夫斯基定理，K₃,₃不是平面图。
    *   C: Petersen图，著名的非平面图，它含有K₃,₃的细分。
    *   D: 这是一个三棱柱图，可以被画在平面上而没有任何边相交，是平面图。

**8. 下面4个图中,所有色数为4的图是( )。**
*   **答案**: A, C, D
*   **考察知识点**: 图论、图的着色、色数。
*   **解析**: 色数是为图的顶点着色，使得任意相邻顶点颜色不同所需要的最少颜色数。
    *   A: 轮图W₆（一个中心点与C₅环上的所有点相连）。C₅需要3种颜色，中心点与这5个点都相邻，需要第4种颜色。所以色数为4。
    *   B: 这是三棱柱图（见第7题），它是3-可着色的。例如，上下两个三角形面分别用(1,2,3)和(1,2,3)着色，再调整使得连接的顶点颜色不同是可行的。其色数为3。
    *   C: 该图包含一个K₄子图（中间四个顶点及其连线），所以至少需要4种颜色。经验证该图可以被4-着色，所以色数为4。
    *   D: 这是二十面体图。它不含K₄，但它不是3-可着色的（这是一个著名结论）。根据四色定理，它是平面图，所以最多需要4色。因此其色数为4。

**9. 下面各图中,( )中的实线边是完备匹配。**
*   **答案**: A
*   **考察知识点**: 图论、匹配、完备匹配（完美匹配）。
*   **解析**: 完备匹配（或完美匹配）是图的一个匹配（即没有公共顶点的边的集合），且该图的所有顶点都被这个匹配中的边所覆盖。
    *   A: 图有8个顶点，实线由4条边构成，这4条边没有公共顶点，且覆盖了全部8个顶点。这是完备匹配。
    *   B: 有两个顶点没有被实线边覆盖。不是完备匹配。
    *   C: 有两个顶点没有被实线边覆盖。不是完备匹配。
    *   D: 图是立方体，有8个顶点。实线构成一个4-环，只覆盖了4个顶点。不是完备匹配。

**10. 某车站有6个入口处...一组9个人进站的方案数为( )。**
*   **答案**: D
*   **考察知识点**: 组合数学、排列组合、可重复排列、隔板法。
*   **解析**: 这个问题可以转化为一个排列问题。我们有9个**不同**的人和 (6-1)=5 个**相同**的隔板（用来分隔6个入口）。将这9个人和5个隔板排成一列。
    *   例如 `P1 P3 | P2 | | P5 P4 P6 | P7 | P8 P9` 表示：P1和P3从入口1按序进入，P2从入口2进入，入口3无人，P5, P4, P6从入口4按序进入，等等。
    *   总共有 9+5 = 14 个位置。
    *   我们可以在这14个位置中为9个不同的人选择9个位置，并且进行排列，方法数是 P(14, 9)。
    *   剩下的5个位置自动留给相同的隔板。
    *   P(14, 9) = 14! / (14-9)! = 14! / 5!。
    *   因此，总方案数为 P(14,9)。

#### **二、填空题**

**1. ...可用A, B, C表示为___**
*   **答案**: (A Δ B) ∩ C
*   **解析**: “只选了离散课和算法课中一门”表示属于A但不属于B，或属于B但不属于A。这正是集合的对称差 (A Δ B)。“并同时选了编译课”表示与集合C取交集。所以最终表达式为 (A Δ B) ∩ C。

**2. ...R的自反、对称、传递闭包tsr(R)是___**
*   **答案**: {(1,1), (2,2), (3,3), (1,3), (3,1)}
*   **解析**: R={(3,1)}。
    *   自反闭包r(R) = R ∪ {(1,1), (2,2), (3,3)}。
    *   对称闭包s(r(R)) = r(R) ∪ {(1,3)} = {(3,1), (1,3), (1,1), (2,2), (3,3)}。
    *   传递闭包t(s(r(R))): 在s(r(R))中，有(1,3)和(3,1)，传递性要求(1,1)和(3,3)必须在闭包中，它们已经存在了。没有其他路径可以生成新的序对。所以最终闭包就是s(r(R))本身。

**3. ...则F∘G⁻¹(x) = ___**
*   **答案**: 1/x² - 2/x + 2
*   **解析**:
    1.  求 G⁻¹(x): 设 y = G(x) = 1/(1+x)。解出x可得 x = 1/y - 1。所以 G⁻¹(x) = 1/x - 1。
    2.  计算复合函数: F∘G⁻¹(x) = F(G⁻¹(x)) = F(1/x - 1) = (1/x - 1)² + 1 = (1/x² - 2/x + 1) + 1 = 1/x² - 2/x + 2。

**4. ...在{90,91, ...,98}中的解的个数为___个。**
*   **答案**: 1
*   **解析**: 2023x ≡ 11 (mod 9)。
    *   简化系数: 2+0+2+3 = 7, 所以 2023 ≡ 7 (mod 9)。11 ≡ 2 (mod 9)。
    *   方程变为 7x ≡ 2 (mod 9)。
    *   因为 7 ≡ -2 (mod 9)，所以 -2x ≡ 2 (mod 9)。
    *   两边同除以-2（或乘以-2的逆元）得 x ≡ -1 (mod 9)，即 x ≡ 8 (mod 9)。
    *   解的形式为 x = 9k + 8。在{90,91,...,98}范围内，只有当k=10时，x = 98。所以只有一个解。

**5. 在同构意义下,4阶自补图有___个。**
*   **答案**: 1
*   **解析**: 自补图是指图G与其补图G同构。n阶自补图存在的充要条件是n≡0或1(mod 4)，且边数m = n(n-1)/4。
    *   对于n=4，满足4≡0(mod 4)。边数 m = 4(3)/4 = 3。
    *   我们需要找4个顶点3条边的不同构的图。只有两种：路径图P₄和星形图K₁,₃。
    *   P₄的补图是它自身，所以P₄是自补图。
    *   K₁,₃的补图是K₃和一个孤立点，两者不同构。
    *   因此只有1个4阶自补图。

**6. 任何非平凡无向树至少有___片树叶。**
*   **答案**: 2
*   **解析**: 非平凡树指顶点数n≥2。树叶是度为1的顶点。可以证明，任何顶点数n≥2的树都至少有两片树叶。这是树的一个基本性质。

**7. ...则G的所有面中,次数最小值为___。**
*   **答案**: 3
*   **解析**: 对于任何简单平面图，每个面都由至少3条边围成（因为不存在重边和环），所以面的次数（边界的边数）至少为3。

**8. ...不能关掉相邻的2盏灯,有___种方法。**
*   **答案**: C(n-k+1, k)
*   **解析**: 这是经典的组合问题。从n个位置中选k个不相邻的位置。可以想象成有n-k个已经亮着的灯，它们形成了n-k+1个空隙（包括两端）。将k个要关掉的灯放入这n-k+1个空隙中，每个空隙最多放一个。方法数是从n-k+1个空隙中选k个，即C(n-k+1, k)。

**9. ...展开式中x₁³x₂¹x₃³x₄¹项的系数是___**
*   **答案**: 17920
*   **解析**: 使用多项式定理。
    *   系数 = (8! / (3!1!3!1!)) × (1)³ × (-1)¹ × (2)³ × (-2)¹
    *   = (40320 / (6×1×6×1)) × 1 × (-1) × 8 × (-2)
    *   = (1120) × 16
    *   = 17920

**10. 递推方程H(n) – H(n − 1) = 7n的通解H(n) = ___**
*   **答案**: A + (7/2)n(n+1) (其中A为任意常数)
*   **解析**:
    *   齐次方程 H(n) - H(n-1) = 0 的通解为 H_h(n) = A (A为常数)。
    *   设特解 H_p(n) = n(an+b) = an² + bn。代入原方程：
    *   (an² + bn) - (a(n-1)² + b(n-1)) = 7n
    *   (an² + bn) - (an² - 2an + a + bn - b) = 7n
    *   2an - a + b = 7n
    *   比较系数得: 2a=7, -a+b=0。解得 a=7/2, b=7/2。
    *   特解为 (7/2)n² + (7/2)n = (7/2)n(n+1)。
    *   通解 H(n) = H_h(n) + H_p(n) = A + (7/2)n(n+1)。

#### **三、判断题**

1.  **×**. 反对称关系指的是若(x,y)∈R且(y,x)∈R则必有x=y。一个关系可以既不是对称的，也不是反对称的。
2.  **×**. 该结论只对**有限**偏序集成立。无限偏序集可能没有极小元，例如整数集Z在"≤"关系下就没有极小元。
3.  **√**. G不为单射，则存在 a₁≠a₂ 使得 G(a₁)=G(a₂)。那么 F(G(a₁))=F(G(a₂))，即(F∘G)(a₁)=(F∘G)(a₂)。由于a₁≠a₂，故F∘G一定不为单射。
4.  **√**. 这是裴蜀定理（Bézout's identity），是数论中的一个基本结论。
5.  **×**. 单向连通图的定义是任意两点u,v之间，或者存在u到v的路径，或者存在v到u的路径。存在一条经过所有顶点的通路（哈密顿通路）是单向连通的**充分条件**，但非必要条件。
6.  **×**. 在树上，任意边都是桥（正确），但只有度大于1的顶点才是割点，树叶（度为1的顶点）不是割点（除非是仅有2个顶点的树）。
7.  **×**. m ≤ 3n-6 是正确的。但 δ(G) ≤ 4 是错误的。平面图只保证最小度 δ(G) ≤ 5。例如正二十面体图是5-正则平面图，其最小度为5。
8.  **√**. 对偶图的构造依赖于平面图的具体嵌入（画法）。同构的图可能有不同的嵌入方式，从而导致它们的对偶图不同构。
9.  **√**. 极大独立集一定是极小支配集，这是一个基本结论。而最大独立集的大小（独立数α(G)）与最小支配集的大小（支配数γ(G)）之间只有γ(G)≤α(G)的关系，不一定相等。所以“未必是”的说法正确。
10. **√**. 将正整数N拆分成r个**正整数**之和的有序拆分（称为组合），其方案数确实是C(N-1, r-1)。题目语境通常指正整数拆分。

#### **四、计算题**

**1. 求换座位的方案数。**
*   **答案**: D(4n-1) + D(4n-2)
*   **考察知识点**: 错排问题（Derangement）。
*   **解析**:
    1.  问题核心是：一个指定的同学（Alex）必须坐到一个指定的新位置上，且其他所有同学也都不能坐回自己的原位。
    2.  设有N=4n个学生。这是一个N个元素的错排问题，但附加了约束。令学生和座位从1到N编号，学生i的原位是i。
    3.  Alex是学生1，他必须坐到座位k (k≠1)。我们需要计算满足 π(i)≠i 对所有i成立，且π(1)=k的排列π的数量。
    4.  对于学生k，他的新座位π(k)有两种情况：
        *   **情况一**: π(k) = 1。即学生1和学生k交换了座位。剩下的N-2个学生必须在剩下的N-2个座位上进行全错排。方案数为 D(N-2)。
        *   **情况二**: π(k) ≠ 1。现在的问题是，将学生{2, ..., N}安排到座位{1, ..., N}\{k}上，要求π(i)≠i (i∈{2,...,N}) 且 π(k)≠1。这可以等价于一个N-1个元素的错排问题：将学生{2, ..., N}安排到座位{1, ..., N}\{k}，其中座位1被“重命名”为座位k。这样，学生i(i≠k)不能坐到座位i，学生k不能坐到“重命名”的座位k（即座位1）。这是一个标准的N-1个元素的错排。方案数为 D(N-1)。
    5.  根据加法原理，总方案数为 D(N-2) + D(N-1)。代入N=4n，得到 D(4n-2) + D(4n-1)。

**2. 求 2023¹¹ mod 9。**
*   **答案**: 4
*   **考察知识点**: 模运算、费马小定理/欧拉定理。
*   **解析**:
    1.  **简化底数**: 计算2023 mod 9。一个数模9的余数等于其各位数字之和模9的余数。2+0+2+3 = 7。所以 2023 ≡ 7 (mod 9)。
    2.  问题转化为计算 7¹¹ mod 9。
    3.  **寻找周期**: 计算7的幂次模9的余数。
        *   7¹ ≡ 7 (mod 9)
        *   7² = 49 ≡ 4 (mod 9)
        *   7³ = 7² × 7 ≡ 4 × 7 = 28 ≡ 1 (mod 9)
    4.  周期为3。我们计算指数11模3的余数。11 = 3 × 3 + 2，所以 11 ≡ 2 (mod 3)。
    5.  因此，7¹¹ ≡ 7² (mod 9)。
    6.  由第3步可知，7² ≡ 4 (mod 9)。所以最终结果是4。

#### **五、证明题**

**1. 证明...无向图构成的集合为可数集。**
*   **考察知识点**: 集合论、可数集、图的同构。
*   **证明**:
    1.  首先，我们考虑顶点被标记的有限图。我们可以限定所有图的顶点都来自自然数集N={1, 2, 3, ...}。
    2.  对于任意固定的n∈N，考虑顶点集为V={1, 2, ..., n}的所有**有标号图**的集合 Gₙ。一个图由其边集唯一确定。V上的可能边的总数为 C(n,2)。每个图对应着边集的一个子集。因此，Gₙ 的大小为 2^C(n,2)，这是一个有限数。
    3.  所有**有限有标号图**的集合 G_labeled 是所有 Gₙ 的并集，即 G_labeled = ∪_{n∈N} Gₙ。这是可数个有限集的并集，因此 G_labeled 是一个可数集。
    4.  题目要求的是**非标定**的图，即图的**同构类**的集合。图的同构关系是 G_labeled 上的一个等价关系。我们要求的集合是这个关系下的所有等价类的集合。
    5.  每一个同构类（非标定图）中都至少包含一个有标号图（例如，将其顶点任意标号为1, 2, ...）。
    6.  因此，存在一个从可数集 G_labeled 到所有图同构类的集合的**满射**函数 f (这个函数将每个有标号图映射到它所属的同构类)。
    7.  可数集的满射像至多是可数的。由于存在无限多个不同构的图（例如，环图C₃, C₄, C₅, ...），所以图的同构类的集合是无穷的。
    8.  综上，所有（非标定的）无向图构成的集合（在同构意义下）是一个可数无穷集，即为可数集。证毕。

**2. 求证: ...顶点v是临界点当且仅当存在含v的最小点覆盖。**
*   **考察知识点**: 图论、点覆盖、临界点。
*   **定义**:
    *   **点覆盖**: 顶点集S⊆V，若图中每条边至少有一个端点在S中，则S为点覆盖。
    *   **最小点覆盖**: 包含顶点数最少的点覆盖。其顶点数记为 α₀(G)。
    *   **临界点**: 顶点v被称为临界点，如果 α₀(G-v) < α₀(G)。
*   **证明**:
    *   **充分性 (⇒)**: **若v是临界点，则存在含v的最小点覆盖。**
        1.  假设v是临界点，由定义 α₀(G-v) < α₀(G)。由于移除一个顶点至多使点覆盖数减1，所以 α₀(G-v) = α₀(G) - 1。
        2.  令 S' 是 G-v 的一个最小点覆盖，则 |S'| = α₀(G-v) = α₀(G) - 1。
        3.  构造集合 S = S' ∪ {v}。则 |S| = |S'| + 1 = (α₀(G) - 1) + 1 = α₀(G)。
        4.  我们证明 S 是 G 的一个点覆盖。对于 G 中的任意边 e=(x,y)：
            *   若 x,y 均不为 v，则 e 是 G-v 中的边。因为 S' 是 G-v 的点覆盖，所以 x 或 y 在 S' 中，从而也在 S 中。
            *   若 x=v，则边 e 的端点 v 在 S 中。
        5.  因此，S 覆盖了 G 的所有边，是 G 的一个点覆盖。
        6.  因为 |S| = α₀(G)，所以 S 是 G 的一个最小点覆盖，且它含有v。
    *   **必要性 (⇐)**: **若存在含v的最小点覆盖，则v是临界点。**
        1.  假设 S 是 G 的一个包含 v 的最小点覆盖。则 |S| = α₀(G)。
        2.  构造集合 S' = S \ {v}。则 |S'| = |S| - 1 = α₀(G) - 1。
        3.  我们证明 S' 是 G-v 的一个点覆盖。对于 G-v 中的任意边 e=(x,y)，x, y 均不为v。
        4.  边 e 也是 G 中的边，因为 S 是 G 的点覆盖，所以 x 或 y 必在 S 中。
        5.  又因为 x, y 都不是 v，所以 x 或 y 必在 S \ {v} 中，即在 S' 中。
        6.  因此 S' 是 G-v 的一个点覆盖。
        7.  这意味着 G-v 存在一个大小为 α₀(G) - 1 的点覆盖。所以 G-v 的最小点覆盖数 α₀(G-v) ≤ |S'| = α₀(G) - 1。
        8.  即 α₀(G-v) < α₀(G)。根据定义，v 是一个临界点。
    *   综上，命题得证。
