**1.** 代数系统 $\langle P(\mathbb{Z}), \oplus, \cup \rangle$ 其中 $P(\mathbb{Z})$ 是整数集的幂集,$\oplus$ 是对称差,$\cup$ 是并运算。下列叙述正确的是( )

- A. 它是环
- B. 它是整环
- C. 它是域
- D. 它是布尔代数

**2.** 语言 $L = \{0^n1^m \mid 0 < n < m\}$ 可以由下列哪种文法生成?( )

- A. 正则文法
- B. 上下文无关文法
- C. 上下文敏感文法
- D. 短语结构文法

**3.** 下列集合中,哪些是不包含子串 "101" 的二进制字符串的集合?( )

- A. $\{0,1\}^* - \{0,1\}^*101\{0,1\}^*$
- B. $(0+11^*0)^*1^*$
> 直接运用分配律

**答案提示**：必要性由模格定义，充分性取 $a\le c$ 则满足模律即为模格。

# 参考答案与解析

## 一、不定项选择题答案

**1. A、D**

**解析**:$\langle P(\mathbb{Z}), \oplus \rangle$ 是阿贝尔群,单位元是 $\varnothing$;$\langle P(\mathbb{Z}), \cup \rangle$ 是半群;且 $\cup$ 对 $\oplus$ 满足分配律,故构成环。又因为 $\cup$ 满足幂等律,且每个元素关于 $\cup$ 有补元(补集),故是布尔代数。但不是整环(存在零因子),也不是域(非空集没有并逆元)。

**2. B、C**

**解析**:$L$ 是上下文无关语言,可由CFG生成,也是上下文敏感语言。但不是正则语言。短语结构文法也能生成,但通常不选。

**3. A、B**

**解析**:A 是补集描述;B 是标准的不含101的正则表达式。C 等价于 $0^*1^*$,不能表示010;D 不正确。

**4. A**

**解析**:Polya定理,$M=\frac{1}{12}(3^6+3\cdot3^4+4\cdot3^3+2\cdot3^2+2\cdot3)=92$。

**5. A、B**

**解析**:由Sylow定理,存在3阶和4阶子群。6阶子群不一定存在(如$A_4$)。12阶群不一定循环。

**6. A、D**

**解析**:分配格的子格仍是分配格;有限格必有最大元和最小元。有补格中补元不一定唯一;模格不一定是分配格。

**7. B、C、D**

**解析**:$m=n-1$ 的图可能不连通;树满足 $m=n-1$;平面图边数上界 $m\le3n-6$;二部图无奇圈。

**8. A、B、C、D**

**解析**:A是逆否推理,B是传递律,C是化简律,D是排中律,都是永真式。

**9. A、C、D**

**解析**:NFA与DFA等价;非确定性下推自动机比确定性更强;图灵机识别递归可枚举语言;正则语言对交封闭。

**10. A、C、D**

**解析**:$\mathbb{Z}$、$\mathbb{Z}_7$、$\mathbb{Z}[x]$ 无零因子;$\mathbb{Z}_6$ 有零因子。

## 二、填空题答案

**1. 20**

**解析**:阶为25当且仅当 $\gcd(a,2025)=81$,个数为 $\phi(25)=20$。

**2. 5**

**解析**:平面图最小度数 $\delta\le5$,且存在平面图达到5。

**3. $\{0^n1^m \mid n\ge0, m\ge2\}$**

**解析**:至少两个1的字符串。

**4. $(1+2n)\cdot3^n$**

**解析**:特征根 $r=3$(重根),代入初值得。

**5. $a^3+3a^2b+b^3$(在 $\mathbb{Z}_5$ 中)**

**解析**:展开得 $a^3+3a^2b-4b^3$,模5后 $-4\equiv1$。

**6. 6**

**解析**:满射数 $=2^3-2=6$。

**7. $0$,$1$**

**解析**:$a\land a'=0$,$a\lor a'=1$。

**8. 12**

**解析**:握手定理 $m=24/2=12$。

**9. 4**

**解析**:真值表中公式为假的情况有4种,故极大项个数为4。

**10. 700**

**解析**:指数生成函数计算,减去0在首位的情况。
