## 一、声音的基本物理性质

声音是音乐的载体，由振动产生。声音有四个物理属性，分别对应音乐中的要素：

| 物理属性 | 音乐要素 | 决定因素 |
|---------|---------|---------|
| 频率 | 音高（pitch） | 振动频率，单位赫兹（Hz） |
| 振幅 | 力度（dynamics） | 振动幅度；空气压力 |
| 持续时间 | 时值（duration） | 声音持续的时间长度 |
| 波形 | 音色（timbre） | 各频率成分的分布及其随时间的变化 |

### 音高

- 人耳可听范围约为 **20 Hz ~ 20 000 Hz**
- 音乐会音高（concert pitch）规定 **A₄ = 440 Hz**
- 人耳对频率的感知是**非线性**的

### 力度与响度

- **力度**由振动幅度（振幅）决定
- **响度**（loudness）由传入耳中的空气压强决定
- 压强单位：帕斯卡（Pa），$1\ \text{Pa} = 1\ \text{N/m}^2 = 1\ \text{kg/(m·s}^2\text{)}$
- 在 1000 Hz 时，人耳听觉下限阈值为 **20 μPa** $= 2 \times 10^{-5}\ \text{Pa}$

### 时值与音色

- **时值**：人耳对时长的感知与物理时长并不完全一致，存在主观时间与客观时间的差异
- **音色**：不同乐器演奏同一音高时波形不同，故能区分

## 二、声压水平与分贝计算

声压水平（sound pressure level, SPL）用于度量声音强弱，定义为：

$$
L_p = 20 \log_{10} \left( \frac{p}{p_0} \right)
$$

其中 $p_0 = 20\ \mu\text{Pa}$ 是 1000 Hz 时的听觉下限阈值，$p$ 是实际声压，单位为分贝（dB）。**0 dB 表示 $p = p_0$，并非没有声音。**

### 对数运算

**基本性质：**

$$
\log_a(xy) = \log_a x + \log_a y, \quad \log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y
$$

**换底公式：**

$$
\log_a x = \frac{\log_b x}{\log_b a}
$$

### 典型计算题

> 已知声压水平从 10 dB 变为 100 dB，求实际声压的比值。

由公式可得：

$$
\frac{p_2}{p_1} = 10^{4.5} \approx 31\,623
$$

## 三、乐音体系

- **乐音**：持续、有规律振动产生的声音
- **噪音**：无规律起伏振动产生的声音
- 传统音乐以乐音为主；20 世纪以来噪音也被大量使用

### 音级与音列

- 具有固定音高的全体乐音构成**乐音体系**，其中的元素称为**音级**（scale step）
- 将音级从低到高排列得到**音列**
- 相邻音级相差一个**半音**（semitone）
- 钢琴键盘上任意相邻琴键（不分黑白）相差半音，隔一个键相差一个**全音**（whole tone）

### 音名与八度

**基本音名**（七个）：C, D, E, F, G, A, B，循环使用于各个八度（octave）。

| 记号 | 说明 |
|-----|------|
| C₄ | 中央 C |
| C₅ | 中央 C 上方八度 |
| C₃ | 中央 C 下方八度 |
| A₀ ~ C₈ | 标准钢琴 88 键范围 |
| C₀ ~ C₈ | Bösendorfer Imperial 290 型（97 键） |

### 变化音级与等音

基本音级（白键）升高或降低半音得到**变化音级**：

| 记号 | 名称 | 效果 |
|-----|------|------|
| ♯ | 升号 | 升高半音 |
| ♭ | 降号 | 降低半音 |
| × | 重升号 | 升高全音 |
| ♭♭ | 重降号 | 降低全音 |
| ♮ | 还原号 | 恢复基本音级 |

**等音**（enharmonic）：同一个琴键可有不同音名，如 E♯ = F、C♭ = B，是历史演变的结果。

## 四、唱名法

唱名（solfège）用音节 **do, re, mi, fa, sol, la, si** 命名音级。

- **mi–fa** 和 **si–do** 之间是半音
- 其余相邻为全音

### 固定唱名法（fixed do）

do 始终等于 C，re = D，依此类推，唱名与音名一一对应。

### 首调唱名法（movable do）

do 可以是任意音级（包括变化音级），按 **全全半全全全半** 规律推出 re, mi 等。

**示例**（1 = D，D 大调）：

| 唱名 | 音名 |
|-----|------|
| do | D |
| re | E |
| mi | F♯ |
| fa | G |
| sol | A |
| la | B |
| si | C♯ |

这决定了调号中升号或降号的数目。

## 五、记谱法

**五线谱**：水平方向代表时间，垂直方向代表音高。

### 音符时值（相对值）

以四分音符为一拍时：

| 音符 | 拍数 |
|-----|------|
| 全音符 | 4 拍 |
| 二分音符 | 2 拍 |
| 四分音符 | 1 拍 |
| 八分音符 | 1/2 拍 |
| 十六分音符 | 1/4 拍 |

- **附点音符**：时值为原音符的 $\frac{3}{2}$ 倍
- **休止符**：有对应符号
![休止符](/assets/courses/music-and-mathematics/img/休止符.png)
- *全在下，二分在上*

### 速度与绝对时值

绝对时值由**速度**（tempo）决定。例如「四分音符 = 60」表示每分钟 60 个四分音符，即每秒 1 个四分音符。

### 谱号

五线谱上的线和间代表什么音高由**谱号**（clef）确定：

| 谱号 | 标记位置 | 表示音高 |
|-----|---------|---------|
| 高音谱号（G 谱号） | 圆圈位于第二线 | 该线为 G₄ |
| 低音谱号（F 谱号） | 冒号中心位于第四线 | 该线为 F₃ |
| 中音谱号（C 谱号） | 中心位于第三线 | 该线为 C₄（中央 C） |
| 次中音谱号 | C 谱号中心位于第四线 | 该线为 C₄ |

高音谱号的下加一线和低音谱号的上加一线一样都是$C_4$

注意，因为一个八度一组里面A在后面，所以G4后面不是A5而是A4，因为实际上两者在一个八度里面。分界的是B和C

## 六、音程

**音程**（interval）是两个音级之间的距离。

- **冠音**：较高的音（上方音）
- **根音**：较低的音（下方音）

音程的名称由**度数**和**半音数**共同确定。

### 度数

从根音到冠音所包含的音名数目（包括两端）。

> 例：D–F 包含 D、E、F 三个音名 → **三度**

### 半音数

音程所包含的半音个数。

| 音程 | 分析 | 半音数 | 名称 |
|-----|------|--------|------|
| D–F | D–E（全音）+ E–F（半音） | 3 | 小三度 |
| F–A | F–G（全音）+ G–A（全音） | 4 | 大三度 |

> 仅靠度数或仅靠半音数都无法唯一确定音程。例如增四度与减五度半音数都是 6，但度数不同（四度 vs 五度）。

- 音程的“度”由字母个数决定；“大/小”由半音数决定。
- 八度的命名规则和其他度数一样，并非唯一。
- 十二平均律中，一个八度被分为12个相等的半音，每个半音乘 $2^{\frac{1}{12}}$，12次后正好乘2。

### 自然音程与变化音程

**自然音程**（diatonic interval）可在白键上直接构成：

纯一度、小二度、大二度、小三度、大三度、纯四度、增四度、减五度、纯五度、小六度、大六度、小七度、大七度、纯八度

**变化音程**（chromatic interval）由自然音程改变半音数得到：

- 大音程或纯音程 **增加** 半音数 → **增音程**
- 小音程或纯音程 **减少** 半音数 → **减音程**

> 例：大二度 C–D 增加半音 → 增二度 C–D♯ 或 C♭–D

## 七、协和音程与不协和音程

### 传统分类

| 类型 | 音程 |
|-----|------|
| **协和**（consonant） | 纯八度、纯五度、纯四度、大三度、小三度、大六度、小六度 |
| **不协和**（dissonant） | 二度、七度、增四度、减五度等 |

协和音程中：纯音程称为**完全协和**，三度、六度称为**不完全协和**。

### 毕达哥拉斯理论

频率比越简单，音程越协和：

| 音程 | 频率比 |
|-----|--------|
| 纯八度 | 2:1 |
| 纯五度 | 3:2 |
| 纯四度 | 4:3 |
| 大六度 | 5:3 |
| 大三度 | 5:4 |
| 小三度 | 6:5 |
| 小六度 | 8:5 |
| 增四度（三全音） | 45:32 |

### 赫尔姆霍茨的拍音理论

两个频率相近的纯音叠加会产生**拍音**（beat）。设频率为 $\omega$ 和 $\omega + \delta$，叠加后振幅受 $\cos(\pi \delta t)$ 调制，每秒钟出现 $\delta$ 次拍音。有几个拍音就和原频率有绝对值的差值

> 拍音理论存在缺陷：同一音程在不同八度中协和性判断会矛盾。

### 心理学视角

斯图姆夫等实验显示，协和音程更容易被未经训练的人听成一个声音。但协和感受受文化影响——例如亚马逊 Tsimane 部落人群对协和与不协和音程无明显偏好。
