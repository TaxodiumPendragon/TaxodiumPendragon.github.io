## 二、“调式、音阶与和弦”课程笔记

### 1. 调式与音阶

调式（mode）是以一个主音（tonic）为中心，按照一定音程关系组织起来的乐音体系。从主音开始按高低次序排列到高八度主音，得到调式音阶（scale）。

- **自然大调**：全、全、半、全、全、全、半。例如C大调：C-D-E-F-G-A-B-C。
- **自然小调**：全、半、全、全、半、全、全。例如a小调：A-B-C-D-E-F-G-A。
- **和声小调**：升高自然小调的VII级半音，形成增二度特征音程。例如a和声小调：A-B-C-D-E-F-#G-A。*这个升高是临时升高，并不写在调号里面*

调号（key signature）表示调式中的固定升降音。关系大小调（调号相同，主音差小三度），平行大小调（主音相同，调号不同）。

### 2. 三和弦

由三个音按三度叠置构成的和弦。从低到高依次为根音、三音、五音。

- **大三和弦**：根音到三音为大三度（4半音），三音到五音为小三度（3半音）。例：C-E-G。
- **小三和弦**：根音到三音为小三度，三音到五音为大三度。例：C-bE-G。
- **增三和弦**：根音到三音、三音到五音均为大三度，根音到五音为增五度。例：C-E-#G。
- **减三和弦**：根音到三音、三音到五音均为小三度，根音到五音为减五度。例：C-bE-bG。

### 3. 七和弦

在三和弦上方再叠加一个七度音（七音）。七和弦共有七种，以根音C为例：

| 名称 | 结构 | 例 |
|------|------|-----|
| 大大七（大七） | 大三和弦+大七度 | C-E-G-B |
| 大小七（属七） | 大三和弦+小七度 | C-E-G-bB |
| 小小七（小七） | 小三和弦+小七度 | C-bE-G-bB |
| 减小七（半减七） | 减三和弦+小七度 | C-bE-bG-bB |
| 减减七（减七） | 减三和弦+减七度 | C-bE-bG-bbB |
| 小大七 | 小三和弦+大七度 | C-bE-G-B |
| 增大七 | 增三和弦+大七度 | C-E-#G-B |

### 4. 和弦转位

- **三和弦**：原位（根音为低音）；第一转位（六和弦，三音为低音，根音与低音相差六度）；第二转位（四六和弦，五音为低音，低音与根音、三音分别相差四度和六度）。
- **七和弦**：原位（根音为低音）；第一转位（五六和弦，三音为低音）；第二转位（三四和弦，五音为低音）；第三转位（二和弦，七音为低音）。

### 5. 调式中的和弦标记

用罗马数字表示根音的级数，大写表示大三和弦，小写表示小三和弦，上标°表示减三，上标+表示增三。七和弦在此基础上添加数字（7、6/5、4/3、2）表示原位或转位。

例如C大调中：
- I：C大三和弦（主和弦）
- ii：d小三和弦
- iii：e小三和弦
- IV：F大三和弦（下属和弦）
- V：G大三和弦（属和弦）
- vi：a小三和弦
- vii°：b减三和弦

### 6. 自然大调与自然小调中的三和弦性质

| 级数 | 自然大调 | 自然小调 |
|------|----------|----------|
| I | 大三 | 小三 |
| II | 小三 | 减三 |
| III | 小三 | 大三 |
| IV | 大三 | 小三 |
| V | 大三 | 小三 |
| VI | 小三 | 大三 |
| VII | 减三 | 大三（自然小调VII级是大三，和声小调中VII级是减七？注意自然小调VII级是b7，构成大三和弦？例如a小调中G-B-D，G是VII级，G-B-D是大三，因为G-B是大三度） |

注意：自然小调VII级是大三和弦（如a小调中G-B-D），而非减三。只有和声小调中升高的VII级才形成减三？实际和声小调VII级是#G-B-D，那是增三？#G-B是小三，B-D是小三，所以是减三？等一下：和声小调中VII级是#G，和弦为#G-B-D，根音到三音小三度，三音到五音小三度，所以是减三和弦。因此自然小调的VII级是大三，和声小调的VII级是减三。

### 7. 常用音程比例回顾（用于和弦频率计算）

- 纯八度：2:1
- 纯五度：3:2
- 纯四度：4:3
- 大三度：5:4
- 小三度：6:5
- 大六度：5:3
- 小六度：8:5
- 大二度：9:8
- 小二度：16:15

这些比例在纯律中用于确定和弦各音的频率，从而得到和谐的三和弦（4:5:6）。

### 8. 小结

本课要求掌握：
- 自然大调、自然小调、和声小调的音阶构成。
- 三和弦与七和弦的种类、结构。
- 和弦转位的概念与标记。
- 调式中各级和弦的标记（罗马数字、大小写、转位符号）。
- 能根据给定调式写出各级和弦，并识别谱例中的和弦及其转位。

## 大调与小调的调号速查表

### 升号调（Sharp Keys）

| 升号数 | 大调 | 小调 | 调号中的升号音 |
|--------|------|------|----------------|
| 0 | C | a | 无 |
| 1 | G | e | F |
| 2 | D | b | F, C |
| 3 | A | f# | F, C, G |
| 4 | E | c# | F, C, G, D |
| 5 | B | g# | F, C, G, D, A |
| 6 | F# | d# | F, C, G, D, A, E |
| 7 | C# | a# | F, C, G, D, A, E, B |

**速记口诀**：升号调顺序 **F C G D A E B**（Father Charles Goes Down And Ends Battle）  
大调主音 = 最后一个升号上方小二度（如一个升号#F，主音为G；两个升号#F、#C，主音为D）

## 降号调（Flat Keys）

| 降号数 | 大调 | 小调 | 调号中的降号音 |
|--------|------|------|----------------|
| 0 | C | a | 无 |
| 1 | F | d | B |
| 2 | Bb | g | B, E |
| 3 | Eb | c | B, E, A |
| 4 | Ab | f | B, E, A, D |
| 5 | Db | bb | B, E, A, D, G |
| 6 | Gb | eb | B, E, A, D, G, C |
| 7 | Cb | ab | B, E, A, D, G, C, F |

**速记口诀**：降号调顺序 **B E A D G C F**（Battle Ends And Down Goes Charles Father）  
大调主音 = 倒数第二个降号（如两个降号B、E，主音为Bb；三个降号B、E、A，主音为Eb）

## 关系大小调
- 关系大小调共享相同的调号，主音相差小三度（3个半音）。
- 大调主音向下小三度得到小调主音（如 C → a，G → e，F → d，Bb → g 等）。
- 小调主音向上小三度得到大调主音（如 a → C，e → G，d → F 等）。

## 等音调（Enharmonic Keys）
- B大调（5个升号）等音于 Cb大调（7个降号）
- F#大调（6个升号）等音于 Gb大调（6个降号）
- C#大调（7个升号）等音于 Db大调（5个降号）
- 实际使用中通常选择升降号较少的调。

## 记忆建议
- 先记住C大调（无升降）、G大调（1个升号）、F大调（1个降号）。
- 升号调：主音 G、D、A、E、B、F#、C#，每个比前一个高纯五度，升号依次增加。
- 降号调：主音 F、Bb、Eb、Ab、Db、Gb、Cb，每个比前一个低纯五度，降号依次增加。
- 小调只需记住关系大调，然后主音向下小三度。
