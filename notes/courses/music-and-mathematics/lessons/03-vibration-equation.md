## 二、振动方程与泛音列课程笔记（基于 PPT equation2026.pdf 及课堂讲解）

### 1. 弦振动的物理模型

假设一条均匀细弦，长度为 L，张力为 T，线密度为 ρ（单位长度质量）。弦两端固定，振动时位移记为 \(u(x,t)\)，其中 x 为位置，t 为时间。

通过牛顿第二定律推导出一维波动方程：

\[
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad c = \sqrt{\frac{T}{\rho}}
\]

边界条件：\(u(0,t) = u(L,t) = 0\)（两端固定）。

### 2. 振动模态与频率

采用分离变量法，解为无穷级数：

\[
u(x,t) = \sum_{n=1}^{\infty} \left( a_n \cos \frac{n\pi c}{L} t + b_n \sin \frac{n\pi c}{L} t \right) \sin \left( \frac{n\pi}{L} x \right)
\]

每一项称为第 n 个振动模态：

\[
u_n(x,t) = \sqrt{a_n^2+b_n^2} \sin(\omega_n t + \theta_n) \sin\left(\frac{n\pi}{L}x\right), \quad \omega_n = \frac{n\pi c}{L}
\]

其振动频率为：

\[
f_n = \frac{\omega_n}{2\pi} = \frac{n}{2L}c = \frac{n}{2L}\sqrt{\frac{T}{\rho}}, \quad n=1,2,3,\dots
\]

当 n=1 时得到基频，即**梅森定律**：

\[
f_1 = \frac{1}{2L}\sqrt{\frac{T}{\rho}}
\]

结论：频率与弦长 L 成反比，与张力 T 的平方根成正比，与线密度 ρ 的平方根成反比。

### 3. 泛音列

由于 \(f_n = n f_1\)，所有泛音频率都是基频的整数倍。序列

\[
f_1,\; 2f_1,\; 3f_1,\; 4f_1,\; \dots
\]

称为泛音列。基音（第一泛音？注意：基音是 f1，第一泛音通常指 f2，第二泛音 f3，依此类推）。

### 例题：HW2 T7

**虚按原理**：手指轻触弦上一点，使该点成为波节（位移恒为零）。只有在该点处有波节的振动模态得以保留；基频模态（\(n=1\)）弦内无中间波节，故被抑制。

**已知**：虚按点 \(A\) 距琴马为整弦长的 \(\dfrac{2}{3}\)，即

\[
x_A = \frac{2}{3}L \quad (L \text{ 为全长})
\]

---

**（1）虚按保留的最低泛音**

两端固定弦的第 \(n\) 模态，波节位于

\[
x = \frac{k}{n}L, \quad k = 0, 1, \ldots, n
\]

要求 \(x_A\) 为波节，即存在整数 \(n, k\) 使

\[
\frac{k}{n} = \frac{2}{3}
\]

最小正整数解为 \(k=2,\; n=3\)。故虚按保留的最低模态为第 3 模态，频率

\[
f_{\text{虚}} = 3 f_1
\]

其中 \(f_1\) 为整根弦的基频。

**（2）实按的音高**

实按 \(A\) 点时，有效弦长 \(d = \dfrac{2}{3}L\)。由梅森定律 \(f \propto 1/L\)：

\[
f_{\text{实}} = \frac{f_1}{2/3} = \frac{3}{2} f_1
\]

**（3）频率比与结论**

\[
\frac{f_{\text{虚}}}{f_{\text{实}}} = \frac{3 f_1}{(3/2) f_1} = 2
\]

频率比为 \(2:1\)，即高一个**纯八度**。虚按 \(A\) 点产生的泛音比实按 \(A\) 点奏出的音高高八度。

### 4. 波节与波腹

在第 n 个模态中，振幅分布由 \(\sin(n\pi x / L)\) 决定。振幅为零的点（\(x = kL/n, k=0,1,\dots,n\)）称为波节，振幅最大的点（\(x = (2k-1)L/(2n)\)）称为波腹。例如：
- n=1：波节在两端，波腹在中点。
- n=2：波节在两端和中央，波腹在 L/4 和 3L/4。

### 5. 拨弦与傅里叶级数

拨弦是特殊初值问题：初始形状为折线（在 x₀ 处拨高 h），初始速度为零。对中点拨弦（x₀ = L/2）求解得到：

\[
a_n = 
\begin{cases}
0, & n\text{ 为偶数} \\
(-1)^{\frac{n-1}{2}} \frac{8}{n^2\pi^2}, & n\text{ 为奇数}
\end{cases}
\]
所有 \(b_n = 0\)。

因此振动中只包含奇数次模态（n=1,3,5,...）。即只产生基频、第三泛音、第五泛音等，没有偶次泛音。这改变了音色，是拨弦与拉弦音色不同的物理原因。

### 6. 谐和音程的泛音列重合理论

赫尔姆霍兹提出：两个音同时发声时，若它们的泛音列重合越多，听觉越协和。

- 八度：高音基频 2f，其泛音列 2f,4f,6f,... 全是低音泛音列 f,2f,3f,... 的偶数项，完全重合 → 完全协和。
- 纯五度：频率比 3:2，高音泛音列 3f/2, 3f, 9f/2, 6f,... 与低音泛音列有一半重合 → 协和。
- 大二度：频率比 9:8，泛音列几乎不重合 → 不协和。

该理论比拍音理论更合理，解释了自然小号（只能吹泛音列中的音）等乐器原理。

### 7. 开管与闭管的泛音列

- 开管（两端开口）：基频 \(f = v/(2L)\)，泛音列 \(f, 2f, 3f, 4f, \dots\)（全部整数倍）。
- 闭管（一端开口，一端封闭）：基频 \(f = v/(4L)\)，泛音列 \(f, 3f, 5f, 7f, \dots\)（只有奇次倍）。

长笛是开管，超吹（overblow）产生高八度。单簧管近似闭管，超吹产生高十二度（3f）。端口校正：管口空气柱振动超出物理管口，需修正长度，朱载堉和徐寿对此有贡献。

### 8. 重要公式汇总

- 梅森定律：\(f_1 = \frac{1}{2L}\sqrt{\frac{T}{\rho}}\)
- 泛音频率：\(f_n = n f_1\)
- 音分值计算：\(c = 1200 \log_2 (f_2/f_1)\)
- 中点拨弦傅里叶系数：\(a_n = 0\)（n 偶），\(a_n = (-1)^{(n-1)/2} \frac{8}{n^2\pi^2}\)（n 奇）
- 开管频率：\(f_n = n \frac{v}{2L}\)
- 闭管频率：\(f_n = (2n-1) \frac{v}{4L}\)

### 9. 常见考点

- 根据梅森定律，已知长度、张力、线密度中任意两个的变化求第三个导致的频率比。
- 判断拨弦、拉弦、按弦等演奏方式产生的泛音列奇偶性。
- 计算给定频率比的音分值。
- 区分开管与闭管乐器的泛音列及其对超吹音程的影响。
- 理解泛音列重合理论解释协和音程。
