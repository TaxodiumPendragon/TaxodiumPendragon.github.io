### 1. 节奏型的表示

> 起拍是有声音的部分，一般假设十六分音符作为一个单位

- **0-1序列**：长度为 N（总拍数），1=起拍，0=休止。
- **圆周模型**：N 个等分点圆，黑点表示起拍。旋转等价于相位变化。
- **距离序列**：设起拍位置 $p_0, p_1, \dots, p_{m-1}$（递增，$p_0=0$），则距离 $d_i = p_{i+1} - p_i$（i=0,...,m-2），$d_{m-1} = N + p_0 - p_{m-1}$。满足 $\sum d_i = N$。

### 2. 节奏奇性

- **定义**：当 N 为偶数时，对径点 $p + N/2 \pmod{N}$。若所有起拍的对径点都不是起拍，则具有节奏奇性。
- **听觉效果**：产生错位感、切分感，增强节奏活力。
- **判断步骤**：
  1. 由距离序列计算起拍位置集合 $P$。
  2. 对每个 $p \in P$ 计算 $q = (p + N/2) \mod N$。
  3. 若存在 $q \in P$，则无奇性；否则具有奇性。
- **例子**：距离序列 (4,2,4,3,3)，N=16。起拍：0,4,6,10,13。对径点：8,12,14,2,5。均不在起拍中，故具有节奏奇性。

### 3. 影子节奏

- **定义**：由相邻起拍的中点构成的节奏（声音不发声，仅数学存在）。中点坐标为 $(p_i + p_{i+1})/2$（模 N，可带半整数）。
- **构造**：
  1. 从起拍位置 $p_0,\dots,p_{m-1}$ 计算中点 $s_i = (p_i + p_{i+1})/2$，下标模 m。
  2. 将 $s_i$ 按圆周顺序排列，得到影子起拍集。
  3. 计算影子距离序列（相邻中点间隔，允许半整数）。
- **例子**：原距离 [3,3,4,2,4]（N=16，起拍0,3,6,10,12）。中点：1.5,4.5,8,11,14。影子距离：[3, 3.5, 3, 3, 3.5]。

### 4. 轮廓与轮廓同构

- **轮廓**：从距离序列 $d_0,\dots,d_{m-1}$ 计算符号序列 $c_i = \text{sign}(d_{i+1} - d_i)$（下标模 m，sign取 +, -, 0）。
- **轮廓同构**：两个轮廓序列可以通过循环移位（旋转）变得完全相同。
- **影子轮廓同构**：原节奏型的轮廓与它的影子节奏的轮廓同构。

### 5. 综合判断练习

- **第9题**：给定距离序列，判断奇性。需计算起拍位置与对径点。
- **第10题**：给定距离序列，判断是否与自身影子轮廓同构。需计算影子距离序列，再计算轮廓，检查循环移位是否匹配。

### 6. 常用公式

- 起拍位置递推：$p_0 = 0$，$p_{i+1} = p_i + d_i$（对 i=0..m-2），最后检查 $p_0 + N = p_{m-1} + d_{m-1}$。
- 对径点：$\text{antipode}(p) = (p + N/2) \mod N$。
- 中点：$(p_i + p_{i+1})/2$（注意加法为实数，结果可能 .5）。
- 轮廓符号（下标模 $m$）：

$$
c_i =
\begin{cases}
+ & \text{if } d_{i+1} > d_i \\
- & \text{if } d_{i+1} < d_i \\
0 & \text{if } d_{i+1} = d_i
\end{cases}
$$

通过上述步骤，你可以在任何给定的距离序列上判断节奏奇性和影子轮廓同构性。这是固定节奏型分析的核心内容，也是本次作业的重点。
