## 02 · Lect 2–5：操作系统与硬件基础

- **Lect 2 · Introduction to OS**：操作系统为什么存在？用资源管理、保护、虚拟化解释它对上层程序的作用。
- **Lect 3 · OS History**：批处理、分时与个人计算机的发展，分别回应了哪些资源和交互需求？
- **Lect 4 · Von Neumann Architecture**：回顾存储程序结构与指令执行，连接 CPU、内存和 I/O。
- **Lect 5 · Hardware Features**：用户态与内核态、特权指令、系统调用、中断与异常；说明一次用户程序进入内核再返回的过程。

**复习抓手**：把“普通函数调用、系统调用、硬件中断”并列比较，说明触发原因、权限变化和状态保存。

## 03 · Lect 6–7：进程与线程

- **Lect 6 · Processes**：进程与程序的区别，地址空间、PCB、状态队列和上下文切换；理解 `fork`、`exec`、`wait`、`exit` 各负责什么。
- **Lect 7 · Threads**：同一进程中的线程共享什么、独享什么；比较用户级与内核级线程，以及抢占式与非抢占式调度。

**自测**：画出进程状态转换；解释一次 `yield` 要保存什么；说清为什么一个线程阻塞是否影响其他线程，取决于实现方式。

## 04 · Lect 8–10：内存与页面置换

- **Lect 8 · Memory Management**：物理／虚拟地址、重定位、内存保护；位图与空闲链表；首次适配、最佳适配、伙伴系统与内外部碎片。
- **Lect 9 · Virtual Memory**：页、页框、页表项，多级页表与 TLB；分段和分页解决的问题有什么不同。练习按页大小拆分页号、偏移，再由页框号求物理地址。
- **Lect 10 · Page Replacement**：请求分页与缺页处理；按引用串比较 OPT、FIFO、LRU、Clock 等算法，手算缺页次数；理解 Belady 异常、局部性、工作集与抖动。

**复习抓手**：画出“虚拟地址 → TLB／页表 → 物理地址”的路径，区分 TLB miss 和 page fault。

## 05 · Lect 11：Windows 虚拟内存

- **硬件翻译路径**（第 4–7 页）：回顾 x86 保护模式、段选择子，以及逻辑地址 → 线性地址 → 物理地址。课件中的 32 位地址布局是教学示例，不应套用到所有 Windows 配置。
- **地址空间与 VAD**（第 10–16 页）：区分无效、保留、提交三种虚拟页状态；理解 VAD 描述地址区间、后备存储和权限，而页表负责具体页映射。
- **缺页分类**（第 16–17 页）：按未提交、权限违例、写时复制、栈增长等情况分析。Hard fault 需要磁盘读取，soft fault 可在内存中满足；不是所有 page fault 都会读盘。
- **实现细节**（第 18–23 页）：页表自映射、进程工作集、PFN 数据库及 free／zeroed／standby／modified／bad 页面链表。

**自测**：解释“预留一段虚拟地址”与“页已驻留物理内存”的区别；把某页移出工作集后又被访问的情况，接到 soft／hard fault 的判断上。

## 06 · Lect 12：Scheduling（I）

- **调度时机与目标**（第 4–13 页）：长期／短期调度、dispatcher、抢占／非抢占；区分 CPU 利用率、吞吐量、周转时间、等待时间与响应时间。只在就绪实体中选择，阻塞任务要先等事件完成。
- **批处理算法**（第 17–27 页）：FCFS、非抢占 SJF、抢占 SJF／SRTF。按到达时间画甘特图，计算平均等待时间，说明长任务可能饥饿的情形；讨论 SJF 最优性时要说明到达条件与运行时间假设。
- **交互式调度**（第 29–39 页）：RR 与时间片大小的取舍、静态／动态优先级。时间片过大会接近 FCFS，过小会增加切换开销。
- **优先级与反馈**（第 40–54 页）：用高、中、低优先级任务解释优先级反转和优先级继承；按课件规则模拟 MLFQ 中队列、优先级与时间片的变化。

**自测**：对同一组任务分别执行 FCFS、SJF／SRTF 与 RR，比较响应、等待和周转时间；不要把“首次运行得快”和“完成得快”混为一谈。

## 07 · 实验课件：从机制回到代码

- **Lab Intro（40 页）**：先确认路线、环境、评分与提交方式。JOS 使用 x86／C、QEMU 和 GDB；Tacos 使用 RISC-V／Rust。JOS 五个项目依次为启动引导、虚拟内存、用户态与系统调用、多任务、文件系统；Tacos 为 Lab 0–3 加额外工作。两条路线不是同一套实验编号。
- **JOS Lab1 Review（14 页）**：沿 BIOS → bootloader → ELF 内核加载 → 保护模式与初始分页串讲；说明 GDT、跳转到高地址、加载地址与链接地址，并回顾 VGA、键盘与 console 初始化。重点关联 Lect 4–5、9。
- **JOS Lab2 Review（20 页）**：物理内存探测、`boot_alloc`、`pages`／`page_free_list`、`mem_init` 后的地址空间、两级页表、页权限与 UVPT 自映射。重点关联 Lect 8–9、11。

**复习方法**：每个已做实验保留三项：实现的机制、一次关键调试、能独立解释的结果。Lab Review 是机制索引，不替代所选路线的任务书或实际代码。

## 08 · 串讲与第一轮自检

用一个典型的阻塞式 `read()` 串起所有模块：

1. 用户线程主动系统调用，内核检查参数与权限；**进入内核不必然发生上下文切换**。
2. 若输入未就绪，当前线程阻塞，调度器从就绪队列中选其他任务。
3. I/O 完成后中断通知内核，将等待者变为就绪；是否立即运行由策略决定。
4. 线程恢复后，访问用户缓冲区需要地址翻译；按具体情况判断 TLB miss、合法缺页或权限错误，再联系 Windows 的缺页分类与页面链表。
5. 完成读取并返回用户态。实际读取也可能命中缓存、不发生阻塞，此处仅作串讲情境。

闭卷检查五组概念：**系统调用／中断／异常，模式切换／上下文切换，进程／线程，TLB miss／page fault，就绪／阻塞**。再补两题：VAD 与页表分别记录什么？RR、SJF 与 MLFQ 分别偏重什么目标？
