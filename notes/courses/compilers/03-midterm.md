你提到的 **自然语言与正则表达式互转**、**构造 DFA 的路径**（Thompson 构造法、是否可以跳过 NFA），是很多同学的卡点。我用最直白的方式 + 典型例题帮你打通。

## 一、自然语言 → 正则表达式（三步法）

**核心方法**：
1. 翻译成“串的模式”：把语言用“允许出现什么”、“不能出现什么”、“位置限制”描述。
2. 分解成基本片段的组合：用连接、选择、闭包表达。
3. 注意边界（开头、结尾、空串 ε）。

### 典型例题 1：二进制串，至少有一个 1
**正则**：`0*1(0|1)*`  
**解释**：先任意个 0，然后一个 1，再任意个 0 或 1。

> 注意：`(0|1)*1(0|1)*` 也可以，但前面 `0*` 已经包含了前面没有 1 的情况，更简洁。

### 例题 2：二进制串，最后两位是 00（前面任意）
**正则**：`(0|1)*00`  
**解释**：任意串后跟两个 0。

### 例题 3：不含子串 001（2016 真题）
**正则**：`(1|01)*0*`  
**解释**：任何不导致 001 的串，可以看作由重复的 1 或 01 组成，最后可以加任意个 0。  
为什么？因为如果出现 00，后面就不能跟 1，只能跟 0，而 01 中的 0 后面是 1，不会造成 001。

**记忆技巧**：类似“禁止模式”的语言，常用“允许的原子单元”的正闭包。

### 例题 4：字母表 {a,b}，每个 a 后面至少跟一个 b（如 ab, abb, bab 等，不能有 a 结尾或 aa）
**正则**：`(b|ab)*`  
**解释**：每个 a 必须和它后面的 b 绑定成 ab，b 可以单独出现，整体任意重复。

### 反向：正则表达式 → 自然语言

- `(0|1)*1(0|1)*` → “至少包含一个 1”
- `(0|1)*00(0|1)*` → “包含子串 00”
- `1*0(0|1)*` → “至少有一个 0，且第一个 0 之前都是 1”

**练习**：自己试着说清楚 `(0|10)*1*` 是什么语言？  
（答案：不含110）

#### 紧急情况下

如果考试中遇到“自然语言描述，求正则表达式”，你可以先用自然语言写出DFA的设计（比如状态表示什么），然后直接画DFA，再从DFA反推正则表达式（用状态消去法，或者Armstrong定理）。这样更保险，因为DFA比正则更直观。

具体做法（仅作应急）：

- 根据语言设计状态（比如记录最后两位、余数等）。
- 画出DFA转移图。
- 用“节点删除法”逐步消去状态，得到正则表达式（龙书3.2.4节，考试一般不要求，但可作为验证）.



## 二、构造 DFA 的路径：必须经过 NFA 吗？Thompson 构造法

### 1. 三条路径

| 路径 | 适用场景 | 考试常见度 |
|------|----------|------------|
| 正则 → NFA（Thompson）→ DFA（子集构造）→ 最小化 | 教科书标准流程，题干明确要求“构造 NFA”或“将正则转化为 DFA” | ⭐⭐⭐⭐ |
| 直接凭经验构造 DFA（如余数状态、关键字符记忆） | 语言描述清晰（如“能被 5 整除”、“含有子串 ab”） | ⭐⭐⭐ |
| 跳过 NFA，从正则直接到 DFA（高级方法，不常用） | 几乎不用 | ⭐ |

**结论**：考试如果给正则表达式，且要求“构造 DFA”，你不一定非要从 NFA 开始，可以直接画 DFA（简单正则）。但如果题中明确“先构造 NFA”，就必须用 Thompson。

### 2. Thompson 构造法（用 ε 边拼接）

**规则记忆口诀**：

- `a` → 两个状态：`s0 -a-> s1`
- `AB` → 把 A 的最后一个状态（接受态）用 ε 边连到 B 的第一个状态
- `A|B` → 新建一个开始状态，ε 到 A 和 B 的开始；A 和 B 的接受态用 ε 边连到一个新的接受态
- `A*` → 新建开始和接受状态，开始 ε 到 A 的开始，A 的接受 ε 回 A 的开始，且开始 ε 到接受，A 的接受 ε 到接受

**例题**：为 `(a|b)*abb` 画 NFA（经典步骤，龙书图 3-26）  
由于画图麻烦，我文字描述顺序：

1. 画 a 的 NFA `(0→a→1)`
2. 画 b 的 NFA `(2→b→3)`
3. 用 `|` 组合 a|b，得新开始 4，新接受 5，4 ε 到 0 和 2，1 和 3 ε 到 5。
4. 用 `*` 对 a|b 做闭包：新开始 6，新接受 7，6 ε 到 4 和 7，5 ε 到 4 和 7。
5. 然后与 a 连接：7 与新的 a 的 NFA 连接（7 ε 到 a 的初态，a 的接受态 8）。
6. 再与 b 连接：8 ε 到 b 的初态，b 的接受态 9。
7. 再与 b 连接：9 ε 到 b 的初态，最后接受态 10。

这样得到 NFA。考试中不需要画这么复杂，但你要会画中等长度的（如 `1(0|1)*(11)*01`）。

**关键点**：Thompson 构造法产生 NFA，然后子集构造法转 DFA（计算 ε 闭包，逐符号求新子集）。

## 三、常见考题：自然语言 → 正则 / 正则 → NFA / 正则 → DFA

**真题举例**：

- **2016 第 1 题**：正则表达式 `0*1*0*1*` 表示的非负二进制数，哪个不能表示偶数？  
  考察正则语言 → 数值性质（只需看末位，最右必须是 0，但这个表达式可以以 1 结尾，所以可以表示奇数）。

- **2016 第 4 题**：不含子串 001 的正则 → 答案 `(1|01)*0*`。

- **2020 第 1 题**：给 NFA 图，要求描述语言并写正则。

- **2017 第 10 题**：给 DFA 图，选等价正则表达式。

**你的训练重点**：

- **自然语言 → 正则**：做 5 道题，比如：
  - 所有二进制串，不含连续两个 0 → `(1|01)*0?`
  - 所有二进制串，包含偶数个 1 → `(0*10*10*)*`
  - 所有由 a,b 组成的串，每个 a 后面至少一个 b → `(b|ab)*`

- **正则 → NFA**：做 2 道中等复杂的，如 `(a|b)*abb`、`1(0|1)*01`。

- **NFA → DFA**：用子集构造法，练习手算 ε 闭包和转移表。

- **DFA 最小化**：把得到的 DFA 按终态/非终态分割，反复细分。

## 四、最后给你一个“不会也能得分”的技巧

如果考试中遇到“自然语言描述，求正则表达式”，你可以先用自然语言写出 DFA 的设计（比如状态表示什么），然后直接画 DFA，再从 DFA 反推正则表达式（用状态消去法，或者 Armstrong 定理）。这样更保险，因为 DFA 比正则更直观。

**具体做法（仅作应急）**：

1. 根据语言设计状态（比如记录最后两位、余数等）。
2. 画出 DFA 转移图。
3. 用“节点删除法”逐步消去状态，得到正则表达式（龙书 3.2.4 节，考试一般不要求，但可作为验证）。
