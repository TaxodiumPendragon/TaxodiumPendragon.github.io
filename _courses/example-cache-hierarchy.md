这是一篇**课程笔记示例**，用来演示归类方式：

| 字段 | 作用 |
|------|------|
| `course` | 属于哪门课（对应 `_data/courses.yml` 里的 slug） |
| `week` | 第几周 / 第几讲（列表排序用） |
| `tags` | 课内主题标签（cache、pipeline…） |

写正文时用普通 Markdown 即可；`bundle exec jekyll build` / `serve` 会转成 HTML。
